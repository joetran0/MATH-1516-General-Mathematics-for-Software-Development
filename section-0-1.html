0.1.1 What Is Programming?

A computer program is a sequence of instructions that tells a computer how to complete a task. Programming is the process of designing, writing, testing, and improving those instructions.

A computer does not automatically understand a mathematical idea written in ordinary language. The idea must be translated into clear steps. For example, suppose we want to calculate the average of three test scores. A possible algorithm is:

  1. Read the three scores.
  2. Add the scores.
  3. Divide the total by 3.
  4. Display the result.

An algorithm is a finite sequence of well-defined steps for solving a problem. A program is an implementation of an algorithm in a programming language.

Mathematics and Programming

In mathematics, we often describe a method using a formula or a sequence of logical steps. Programming requires the same kind of precise reasoning. The main difference is that every instruction must be written in a form the computer can interpret.

Input, Processing, and Output

Many programs can be understood using the following three-stage model:

Stage Meaning Example
Input Information supplied to the program Three test scores
Processing Calculations or decisions performed by the program Add the scores and divide by 3
Output Information produced by the program The average score

0.1.2 What Is Python?

Python is a general-purpose programming language. It can be used to create applications, automate tasks, analyze data, perform scientific calculations, and build mathematical models.

Python is called a high-level language because its commands are designed to be readable by people. Consider the instruction below: 

print("Hello, MATH 1516!")

Even without previous programming experience, you can probably predict that this instruction displays the message: 

Hello, MATH 1516!

Why Use Python?

  • Readable syntax: Python code is generally concise and close to ordinary mathematical thinking.
  • Free and widely available: Python can be installed and used without purchasing a licence.
  • Large collection of packages: Additional tools are available for mathematics, statistics, visualization, and scientific computing.
  • Useful beyond this course: Python is used in software development, data science, artificial intelligence, research, and automation.
  • Interactive experimentation: You can change a value, run the code again, and immediately observe the effect.

Python in MATH 1516

We will use Python to support the four mathematical parts of the course:

Course Part Possible Uses of Python
Linear Systems Create matrices, perform matrix operations, solve systems, and visualize matrix entries
Differential Calculus Plot functions, approximate derivatives, and perform symbolic differentiation
Statistics Summarize datasets and create histograms, box plots, and scatter plots
Probability Simulate random experiments and investigate probability distributions

Python Supports the Mathematics

Python will not replace mathematical reasoning. It will help us calculate, visualize, experiment, and check our understanding. You should still be able to explain what the code is doing and why the result makes sense.

0.1.3 A First Look at Python Code

Displaying Output

The print function displays information. Text must be placed inside quotation marks. 

print("Welcome to Python")
print(2 + 3)

The output is:

Welcome to Python
5

The first line prints text. The second line asks Python to calculate 2 + 3 and print the result.

Python as a Calculator

Operation Python Symbol Example Result
Addition+7 + 411
Subtraction-7 - 43
Multiplication*7 * 428
Division/7 / 41.75
Exponentiation**2 ** 38
Remainder%7 % 43

Multiplication Must Be Written Explicitly

In mathematics, we may write (3x). In Python, multiplication must use an asterisk: 3 * x. Writing 3x produces an error.

Variables

A variable is a name that refers to a stored value. The equals sign assigns the value on the right to the name on the left. 

length = 8
width = 5
area = length * width

print(area)

The output is:

40

This program stores the values 8 and 5, multiplies them, stores the result using the name area, and then displays that result.

Try It 0.1A

Without running the code, predict the output:

x = 4
y = 3
z = x ** 2 + y ** 2
print(z)
Check your prediction

The output is 25 because (4^2 + 3^2 = 16 + 9 = 25).

Comments

A comment is a note for a person reading the program. Python ignores any text on a line after the number sign #. 

# Calculate the area of a rectangle
length = 8
width = 5
area = length * width

print(area)

Comments can explain the purpose of a calculation, record an assumption, or make longer programs easier to understand.

Syntax

Every programming language has rules that determine how instructions must be written. These rules are called syntax. For example, the following statement is missing a closing quotation mark: 

print("Hello)

Python cannot interpret the instruction and reports a SyntaxError. Error messages are not signs of failure; they are information that helps us locate and correct a problem.

0.1.4 Worked Examples

Example 1: Evaluating a Mathematical Expression

Use Python to evaluate

3(5 + 2)2 - 4.

result = 3 * (5 + 2) ** 2 - 4
print(result)

Python follows the usual order of operations. It first calculates 5 + 2, then squares the result, multiplies by 3, and subtracts 4. The output is: 

143

Example 2: Converting Temperature

The formula for converting a temperature from Celsius to Fahrenheit is

F = (9/5)C + 32.

celsius = 20
fahrenheit = (9 / 5) * celsius + 32

print(fahrenheit)

The program produces the output 68.0.

In this example, the input is the value stored in celsius, the processing is the temperature formula, and the output is the value stored in fahrenheit.

Example 3: Distance Between Two Points

The distance between ((x_1,y_1)) and ((x_2,y_2)) is

d = √((x2 - x1)2 + (y2 - y1)2).

x1 = 1
y1 = 2
x2 = 4
y2 = 6

distance_squared = (x2 - x1) ** 2 + (y2 - y1) ** 2
distance = distance_squared ** 0.5

print(distance)

Since the horizontal change is 3 and the vertical change is 4, the program calculates (sqrt{3^2+4^2}=5). The output is 5.0.

Try It 0.1B

Modify Example 3 so that it calculates the distance between ((-2,1)) and ((3,13)). Predict the answer before running the program.

Show answer

The changes are (3-(-2)=5) and (13-1=12). Therefore, the distance is (sqrt{5^2+12^2}=sqrt{169}=13).

0.1.5 The Programming Process

Writing code is usually an iterative process:

  1. Understand the problem. Identify what is known and what must be found.
  2. Design an algorithm. Write the required steps in a logical order.
  3. Translate the algorithm into code. Express each step using valid Python syntax.
  4. Run the program. Allow Python to execute the instructions.
  5. Test the result. Try values for which the expected answer is known.
  6. Debug and improve. Correct errors and make the program clearer.

Debugging is the process of finding and correcting errors in a program. Even experienced programmers debug their code regularly.
