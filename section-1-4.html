1.4.2 What Is a Linear System?

A linear system is a collection of linear equations involving the same variables. For example:

2x + 3y = 7
−x + 4y = 5

The numbers multiplying the variables are the coefficients. The numbers on the right are the constants.

EquationCoefficient of xCoefficient of yConstant
2x + 3y = 7237
−x + 4y = 5−145

1.4.3 The Equation Ax = b

The system above can be written compactly as:

Ax = b
SymbolNameContents
ACoefficient matrixThe coefficients from the left side of the equations
xVariable vectorThe unknown variables, in a fixed order
bConstant vectorThe constants from the right side of the equations
 
A = np.array([
    [ 2, 3],
    [-1, 4]
])

x = np.array([x_value, y_value])
b = np.array([7, 5])

Variable Order Must Stay Fixed

If the variable vector is ordered as [x, y], every row of A must list the coefficient of x first and the coefficient of y second.

1.4.4 Why Matrix Multiplication Reproduces the Equations

Each entry of Ax is a row of A dotted with the variable vector:

[2, 3] · [x, y] = 2x + 3y
[−1, 4] · [x, y] = −x + 4y

Therefore, the matrix equation contains exactly the same information as the original system.

1.4.5 Dimensions

A system with m equations and n variables has the following dimensions:

ObjectDimensionsMeaning
Am × nOne row per equation and one column per variable
xn entriesOne entry per variable
bm entriesOne entry per equation

Thus, an m × n matrix multiplied by a length-n vector produces a length-m vector.

print("A shape:", A.shape)
print("b shape:", b.shape)

1.4.6 From Equations to Matrix Form

Consider the system:

3x − 2y + z = 4
5y − 3z = −1
2x + y + 4z = 10

Translation Procedure

  1. Choose and record a variable order: x, y, z.
  2. Write one coefficient row for each equation.
  3. Use zero when a variable is missing.
  4. Place the right-side constants in b.
A = np.array([
    [3, -2,  1],
    [0,  5, -3],
    [2,  1,  4]
])

b = np.array([4, -1, 10])

Do Not Skip Missing Variables

The second equation has no x-term, so its coefficient row begins with 0. Omitting that zero would shift the remaining coefficients into the wrong columns.

1.4.7 Standard Form First

Before forming matrices, put every variable term on the left and every constant on the right.

Example

Rewrite x + 8 = 3y as:

x − 3y = −8

The correct coefficient row is [1, -3], and the constant is -8.

This step prevents sign errors when extracting coefficients.

1.4.8 From Matrix Form to Equations

Suppose:

A = np.array([
    [ 1,  0, -2],
    [ 3,  4,  1]
])

b = np.array([6, -5])

Using the variable order x, y, z, the corresponding equations are:

x − 2z = 6
3x + 4y + z = −5

A zero coefficient may be omitted when writing the equation, but its position must remain present in the matrix.

1.4.9 The Augmented Matrix

The augmented matrix places the constant vector beside the coefficient matrix. It is written [A | b].

A = np.array([
    [ 2, 3],
    [-1, 4]
])

b = np.array([7, 5])

augmented = np.column_stack((A, b))
print(augmented)
[[ 2  3  7]
 [-1  4  5]]

If A has shape (m, n), then [A | b] has shape (m, n + 1).

The Bar Is Not Another Variable

The vertical bar separates coefficients from constants. The final column belongs to b, not to the coefficient matrix.

1.4.10 Verifying a Candidate Solution

A vector x solves the system exactly when Ax = b.

A = np.array([
    [2, 1],
    [1, 3]
])

b = np.array([5, 5])
candidate = np.array([2, 1])

left_side = A @ candidate

print("A @ candidate:", left_side)
print("b:", b)
print("Is a solution?", np.allclose(left_side, b))
A @ candidate: [5 5]
b: [5 5]
Is a solution? True

np.allclose() is useful when decimal calculations may introduce tiny rounding differences.

A Reusable Function

def is_solution(A, x, b):
    """Check whether x approximately satisfies A @ x = b."""
    return np.allclose(A @ x, b)

print(is_solution(A, candidate, b))

1.4.11 Homogeneous Systems

A homogeneous system has zero on the right side:

Ax = 0
A = np.array([
    [1,  2, -1],
    [3, -1,  4]
])

b = np.zeros(2)

The zero vector always satisfies a homogeneous system because A0 = 0. Some homogeneous systems also have nonzero solutions.

1.4.12 Applied Example: Ticket Sales

A tutorial fundraiser sells student tickets for $6 and general tickets for $10. It sells 80 tickets and receives $620.

Let s be the number of student tickets and g the number of general tickets.

s + g = 80
6s + 10g = 620 
A = np.array([
    [1,  1],
    [6, 10]
])

b = np.array([80, 620])

The first row describes the total number of tickets. The second describes the total revenue. Defining the variables before building the matrix gives every row and column a clear meaning.

1.4.14 Common Errors

ProblemCauseCorrection
Coefficients appear in the wrong columnsThe variable order changed between equations.Choose one order and use it in every row.
A row is too shortA missing variable was skipped.Insert a zero coefficient.
A coefficient has the wrong signThe equation was not put in standard form first.Move variable terms left and constants right before recording values.
A @ x gives a dimension errorThe number of columns of A differs from the length of x.Use one variable-vector entry for each column of A.
The augmented matrix has the wrong shapeb does not have one entry per equation.Check that len(b) == A.shape[0].

Section Summary

  • A linear system can be written compactly as Ax = b.
  • Rows of A correspond to equations; columns correspond to variables.
  • Variable order must remain consistent throughout the matrix.
  • A missing variable contributes a zero coefficient.
  • For m equations and n variables, A has order m × n.
  • The augmented matrix [A | b] appends the constants as one final column.
  • A candidate is a solution precisely when Ax equals b.
