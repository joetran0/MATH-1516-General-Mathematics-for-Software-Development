Learning Objectives

By the end of this section, you should be able to:

  • interpret a solution vector using the chosen variable order;
  • verify a numerical solution by substitution and matrix multiplication;
  • calculate and interpret a residual vector;
  • recognize when a system has a unique solution, no solution, or infinitely many solutions;
  • handle a singular-matrix error appropriately;
  • explain why explicitly computing an inverse is usually unnecessary; and
  • use least squares for a simple overdetermined system.

1.5.1 Begin in Google Colab

Open a Google Colab notebook and run:

import numpy as np

NumPy's linear-algebra tools are available through np.linalg.

1.5.2 What Does It Mean to Solve a System?

For a system written as Ax = b, solving means finding every vector x that makes the equation true.

A linear system may have:

Solution TypeMeaningGeometric Picture in Two Variables
One solutionExactly one vector satisfies all equations.Two distinct lines intersect once.
No solutionNo vector satisfies every equation.Two distinct parallel lines.
Infinitely many solutionsMore than one vector satisfies the system.Two equations describe the same line.

np.linalg.solve() is intended for square systems with a unique solution.

1.5.3 Solving a 2 × 2 System

Consider:

2x + y = 5
x + 3y = 5 
A = np.array([
    [2, 1],
    [1, 3]
])

b = np.array([5, 5])

solution = np.linalg.solve(A, b)
print(solution)
[2. 1.]

Since the variable order is x, y, the output means x = 2 and y = 1.

Standard Workflow

  1. Put the equations in standard form.
  2. Create the coefficient matrix A.
  3. Create the constant vector b.
  4. Run solution = np.linalg.solve(A, b).
  5. Interpret entries in the original variable order.
  6. Verify the result.

1.5.4 Solving a 3 × 3 System

x + y + z = 6
2x − y + z = 3
x + 2y − z = 2 
A = np.array([
    [1,  1,  1],
    [2, -1,  1],
    [1,  2, -1]
], dtype=float)

b = np.array([6, 3, 2], dtype=float)

solution = np.linalg.solve(A, b)
print(solution)
[1. 2. 3.]

The solution is x = 1, y = 2, and z = 3.

Why Decimal Output Appears

Numerical linear-algebra routines generally return floating-point values, even when the exact solution consists of integers.

1.5.5 Verifying the Solution

Substitute the computed vector back into the matrix equation:

left_side = A @ solution

print("A @ solution:", left_side)
print("b:", b)
print("Verified:", np.allclose(left_side, b))

np.allclose() allows for very small floating-point differences.

Checking Individual Equations

x, y, z = solution

print(x + y + z)
print(2*x - y + z)
print(x + 2*y - z)

The outputs should be close to 6, 3, and 2.

1.5.6 Residuals

The residual vector measures how closely a candidate satisfies the system:

r = Ax − b
residual = A @ solution - b
residual_size = np.linalg.norm(residual)

print("Residual:", residual)
print("Residual norm:", residual_size)

For an accurately computed exact solution, the residual norm should be zero or extremely small.

Small Does Not Always Mean Exactly Zero

Floating-point arithmetic can produce values such as 2.2e-16. This is extremely close to zero and is normally caused by rounding.

1.5.7 Determinants and Unique Solutions

For a square matrix A:

  • if det(A) ≠ 0, then A is invertible and the system has a unique solution for every b;
  • if det(A) = 0, then A is singular and a unique solution is impossible.
determinant = np.linalg.det(A)
print(determinant)

Use the Solver to Solve

The determinant is useful for mathematical interpretation, but you do not need to calculate it before every call to np.linalg.solve().

1.5.8 Why Not Compute the Inverse?

If A is invertible, algebra gives x = A−1b. NumPy can imitate this:

solution_inverse = np.linalg.inv(A) @ b

However, when the goal is to solve one system, prefer:

solution = np.linalg.solve(A, b)

The direct solver avoids explicitly constructing the inverse and more clearly expresses the intended calculation.

Do Not Use 1 / A

1 / A divides 1 by each entry. It does not compute a matrix inverse.

1.5.9 Singular Systems

Consider a system in which the second equation is twice the first:

x + 2y = 3
2x + 4y = 6 
A = np.array([[1, 2], [2, 4]], dtype=float)
b = np.array([3, 6], dtype=float)

np.linalg.solve(A, b)

NumPy raises a LinAlgError: Singular matrix. Here the equations describe the same line, so there are infinitely many solutions.

A System with No Solution

If the same matrix is paired with b = [3, 7], the left sides remain multiples but the right sides do not. The equations are inconsistent, so there is no solution. The coefficient matrix is still singular.

1.5.10 Handling Solver Errors

try:
    solution = np.linalg.solve(A, b)
    print("Solution:", solution)
except np.linalg.LinAlgError:
    print("The coefficient matrix is singular or unsuitable for solve().")

Catching the error prevents the notebook from stopping and gives you an opportunity to inspect the system.

1.5.11 Non-Square Systems and Least Squares

np.linalg.solve() requires a square coefficient matrix. An overdetermined system has more equations than variables and may not have an exact solution.

A = np.array([
    [1, 1],
    [1, 2],
    [1, 3]
], dtype=float)

b = np.array([2, 2.9, 4.1])

solution, residuals, rank, singular_values = np.linalg.lstsq(
    A, b, rcond=None
)

print("Least-squares solution:", solution)
print("Residual vector:", A @ solution - b)

The least-squares solution minimizes the size of Ax − b. It is an approximation, not necessarily an exact solution to every equation.

Where Least Squares Appears

Least squares is used in data fitting and linear regression, where measured data may not lie exactly on one model.

1.5.12 Applied Example: Ticket Sales

Recall the system from Section 1.4:

s + g = 80
6s + 10g = 620 
A = np.array([[1, 1], [6, 10]], dtype=float)
b = np.array([80, 620], dtype=float)

solution = np.linalg.solve(A, b)
s, g = solution

print("Student tickets:", s)
print("General tickets:", g)
print("Verified:", np.allclose(A @ solution, b))

The result is 45 student tickets and 35 general tickets. Both values make sense in context: they are nonnegative whole numbers, total 80, and produce $620 in revenue.

1.5.13 A Reusable Solver Function

def solve_and_check(A, b):
    """Solve A @ x = b and report the residual norm."""
    try:
        x = np.linalg.solve(A, b)
    except np.linalg.LinAlgError:
        return None, None

    residual_norm = np.linalg.norm(A @ x - b)
    return x, residual_norm

A = np.array([[2, 1], [1, 3]], dtype=float)
b = np.array([5, 5], dtype=float)

x, error = solve_and_check(A, b)
print(x)
print(error)

1.5.15 Common Errors

LinAlgError: Last 2 dimensions must be squareA is not square.Use solve only for square systems; consider least squares when appropriate.
LinAlgError: Singular matrixThe system does not have a unique solution.Inspect dependence and consistency instead of forcing a solve.
Wrong numerical answerCoefficients, constants, or variable order were entered incorrectly.Reconstruct A and b from the original equations.
Verification fails slightlyFloating-point rounding is present.Use np.allclose() and inspect the residual norm.

Section Summary

  • np.linalg.solve(A, b) solves a square, full-rank system.
  • The solution vector must be interpreted in the chosen variable order.
  • Verify a solution using np.allclose(A @ x, b).
  • The residual A @ x - b measures the discrepancy in a proposed or computed solution.
  • A singular coefficient matrix does not produce a unique solution.
  • Use the direct solver instead of explicitly constructing an inverse.
  • Least squares provides a best-fitting solution when an exact non-square system solution may not exist.
