2.1.2 Functions as Input-Output Rules

A function assigns exactly one output to each allowed input. The notation y = f(x) says that:

  • x is the input, or independent variable;
  • f is the name of the function; and
  • f(x) is the output, or dependent variable.

Example: A Polynomial

Consider

f(x) = x2 − 3x + 2.

Substituting x = 4 gives f(4) = 42 − 3(4) + 2 = 6.

2.1.3 Defining a Function in Python

The same polynomial can be written as a Python function:

def f(x):
    return x**2 - 3*x + 2
CodeMeaning

Python Multiplication and Powers

Write 3*x, not 3x. Use ** for powers. In Python, ^ does not mean exponentiation.

2.1.4 Evaluating a Function

After running the definition cell, call the function by putting an input in parentheses:

print(f(0))   # 2
print(f(1))   # 0
print(f(4))   # 6

A function call can also be used inside a larger calculation:

difference = f(4) - f(1)
print(difference)   # 6

return Is Not the Same as print

print displays information. return produces a result that another calculation can use.

def show_square(x):
    print(x**2)

result = show_square(3)
print(result)   # None

The function displays 9, but it does not return 9. When a function reaches its end without a return statement, its result is None.

Rule of Thumb

For mathematical functions, return the answer. Print it only when you want to display it.

2.1.5 Parameters and Local Variables

A function can perform several steps before returning a result. Variables created inside it are local to that function.

def average_rate_change(a, b):
    change_in_output = f(b) - f(a)
    change_in_input = b - a
    return change_in_output / change_in_input

print(average_rate_change(1, 4))   # 2.0

This function has two parameters, a and b. Their order matters when the function is called.

A Function with Several Parameters

def linear(x, m, b):
    return m*x + b

print(linear(3, 2, -1))   # 5

Here, x is the input, m is the slope, and b is the vertical intercept.

2.1.7 Domains and Invalid Inputs

The domain is the set of inputs for which a function is defined. Python does not automatically know the intended real-number domain.

FunctionReal-number restriction
np.sqrt(x - 2)x ≥ 2
np.log(x)x > 0
1 / (x - 3)x ≠ 3
 
def reciprocal_shift(x):
    if x == 3:
        raise ValueError("x cannot equal 3")
    return 1 / (x - 3)

Warnings Can Reveal a Domain Problem

For an invalid NumPy input, Colab may show a warning and produce nan (not a number) or inf (infinity). Do not treat those values as ordinary outputs.

2.1.8 Evaluating Many Inputs

Our first function uses operations that NumPy applies element by element. We can therefore give it an entire array:

x_values = np.array([-2, -1, 0, 1, 2])
y_values = f(x_values)

print(y_values)   # [12  6  2  0  0]

np.linspace(start, stop, number) creates evenly spaced inputs, including both endpoints:

x_values = np.linspace(-2, 4, 7)
y_values = f(x_values)

print(x_values)
print(y_values)

Why NumPy Instead of math?

The standard math module is convenient for single numbers. NumPy functions also accept arrays, which will be useful when we plot functions in Section 2.2.

2.1.9 Composing Functions

The composition (f ∘ g)(x) means f(g(x)). The output of g becomes the input of f.

def g(x):
    return 2*x + 1

def h(x):
    return f(g(x))

print(h(2))       # f(g(2)) = f(5) = 12
print(g(f(2)))    # g(f(2)) = g(0) = 1

Usually, f(g(x)) and g(f(x)) are different. Read a composition from the inside outward.

2.1.10 Piecewise-Defined Functions

A scalar piecewise function can use if:

def absolute_value(x):
    if x < 0:
        return -x
    return x

print(absolute_value(-5))   # 5
print(absolute_value(3))    # 3

For an array, use np.where(condition, value_if_true, value_if_false):

p(x) = { x2 if x < 0;   2x + 1 if x ≥ 0 } 
def piecewise(x):
    x = np.asarray(x)
    return np.where(x < 0, x**2, 2*x + 1)

inputs = np.array([-2, -1, 0, 1, 2])
print(piecewise(inputs))   # [4 1 1 3 5]

2.1.11 An Applied Function

Suppose a printing job has a fixed setup cost of $25 and costs $4.50 per copy.

def total_cost(quantity, fixed_cost=25, unit_cost=4.50):
    return fixed_cost + unit_cost*quantity

print(total_cost(20))           # 115.0
print(total_cost(20, 30, 4.25)) # 115.0

The last two parameters have default values. A caller may use the defaults or provide different values.

import numpy as np

def p(x):

print(p(0))    # 4

x_values = np.linspace(-2, 2, 9)

def q(x):
    return np.sqrt(x + 3)

# Domain of q: x >= -3

    x = np.asarray(x)
    return np.where(x < 1, x + 2, x**2)

Section Summary

  • A function maps every allowed input to exactly one output.
  • Python functions use def, parameters, an indented body, and usually return.
  • Explicit multiplication and ** translate standard algebra into Python.
  • NumPy functions make definitions work naturally with arrays.
  • Every formula must be considered together with its domain.
  • Functions can be composed and defined piecewise.
  • Arrays and value tables prepare us to plot functions in Section 2.2.
