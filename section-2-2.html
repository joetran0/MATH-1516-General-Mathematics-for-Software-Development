Learning Objectives

By the end of this section, you should be able to:

  • generate function inputs with NumPy;
  • create a line graph with Matplotlib;
  • distinguish a Figure from an Axes;
  • add titles, axis labels, grids, and legends;
  • control the viewing window and sampling density;
  • plot several functions on one set of axes;
  • respect domain restrictions and discontinuities; and
  • use graphs to describe important function behaviour.

2.2.1 Begin in Google Colab

Open a Google Colab notebook and run:

import numpy as np
import matplotlib.pyplot as plt

NumPy will create and evaluate arrays. Matplotlib will turn those numerical values into graphs. Both packages are already available in Colab.

2.2.2 From a Function to a Graph

A graph displays ordered pairs of the form (x, f(x)). A computer approximates the curve by:

  1. choosing many input values;
  2. evaluating the function at those inputs; and
  3. joining the resulting points with short line segments.

The Basic Plotting Workflow

  1. Define the function.
  2. Create an array of x-values.
  3. Calculate the matching y-values.
  4. Create a Figure and Axes.
  5. Plot and label the data.
  6. Display the figure.

2.2.3 Your First Function Plot

Graph f(x) = x2 − 3x + 2 on −2 ≤ x ≤ 5.

def f(x):
    return x**2 - 3*x + 2

x = np.linspace(-2, 5, 400)
y = f(x)

fig, ax = plt.subplots()
ax.plot(x, y)
plt.show()

np.linspace(-2, 5, 400) creates 400 evenly spaced inputs. More sample points usually make a smooth function appear smoother.

Object or commandPurpose
figThe entire Figure, including every graph and its surrounding space.
axThe Axes: the region containing the plotted data, scales, ticks, and labels.
ax.plot(x, y)Plots the paired coordinates from x and y.
plt.show()Displays the completed Figure. Colab often displays it automatically, but this command makes the intention explicit.

Arrays Must Match

The x and y arrays should contain the same number of entries. Defining y = f(x) normally guarantees this.

2.2.4 Make the Graph Readable

A mathematical graph should identify its variables and purpose.

fig, ax = plt.subplots(figsize=(7, 4.5))

ax.plot(x, y, color="maroon", linewidth=2, label=r"$f(x)=x^2-3x+2$")
ax.set_title("Graph of a Quadratic Function")
ax.set_xlabel("x")
ax.set_ylabel("f(x)")
ax.grid(True, alpha=0.3)
ax.legend()

plt.show()
OptionExampleEffect
Colourcolor="maroon"Changes the line colour.
Widthlinewidth=2Makes the line thicker.
Stylelinestyle="--"Uses a dashed line.
Markermarker="o"Marks the sampled points.
Labellabel="f(x)"Supplies text for the legend.
Transparencyalpha=0.5Makes an object partly transparent.

Mathematics in Labels

Text between dollar signs is typeset as mathematics. Prefixing the string with r, as in r"$x^2$", is useful when the expression contains backslashes.

2.2.5 Add Coordinate Axes

Horizontal and vertical reference lines can make intercepts and signs easier to see.

fig, ax = plt.subplots(figsize=(7, 4.5))
ax.plot(x, y, color="maroon", linewidth=2)

ax.axhline(0, color="black", linewidth=1)
ax.axvline(0, color="black", linewidth=1)
ax.set_xlabel("x")
ax.set_ylabel("f(x)")
ax.set_title("Quadratic with Coordinate Axes")
ax.grid(True, alpha=0.3)

plt.show()

ax.axhline(0) draws y = 0, the horizontal axis. ax.axvline(0) draws x = 0, the vertical axis.

2.2.6 Choose the Viewing Window

The viewing window determines which portion of the graph is visible.

fig, ax = plt.subplots(figsize=(7, 4.5))
ax.plot(x, y, color="maroon", linewidth=2)

ax.set_xlim(-2, 5)
ax.set_ylim(-2, 12)
ax.grid(True, alpha=0.3)

plt.show()
  • ax.set_xlim(left, right) sets the horizontal window.
  • ax.set_ylim(bottom, top) sets the vertical window.

A Window Can Mislead

A narrow window may hide intercepts, turning points, asymptotes, or long-term behaviour. A very wide window may flatten important local details. Try more than one window before drawing conclusions.

Sampling Density

x_coarse = np.linspace(-2, 5, 8)
x_smooth = np.linspace(-2, 5, 400)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(10, 4))
ax1.plot(x_coarse, f(x_coarse), marker="o")
ax1.set_title("8 sample points")

ax2.plot(x_smooth, f(x_smooth))
ax2.set_title("400 sample points")

plt.show()

Sampling does not change the function. It changes how accurately the drawn line represents it.

2.2.7 Plot Multiple Functions Together

Plotting several functions on the same Axes makes comparisons and intersections visible.

def linear(x):
    return 2*x + 1

def quadratic(x):
    return x**2 - 3*x + 2

x = np.linspace(-2, 5, 400)

fig, ax = plt.subplots(figsize=(7, 4.5))
ax.plot(x, linear(x), label=r"$y=2x+1$", linewidth=2)
ax.plot(x, quadratic(x), label=r"$y=x^2-3x+2$", linewidth=2)

ax.axhline(0, color="black", linewidth=0.8)
ax.axvline(0, color="black", linewidth=0.8)
ax.set_xlabel("x")
ax.set_ylabel("y")
ax.set_title("Comparing Two Functions")
ax.grid(True, alpha=0.3)
ax.legend()

plt.show()

An intersection represents an input where the functions have equal outputs. The graph provides an estimate; algebra or numerical methods can produce a more precise value.

Use a Legend

Give every curve a label, then call ax.legend(). Colour alone may be inaccessible or unclear when a graph is printed.

2.2.8 Plot Only the Domain

For g(x) = √(x − 2), the real-number domain is x ≥ 2. Generate inputs from that domain:

def g(x):
    return np.sqrt(x - 2)

x = np.linspace(2, 10, 400)

fig, ax = plt.subplots(figsize=(7, 4.5))
ax.plot(x, g(x), color="green", linewidth=2)
ax.set_title(r"$g(x)=\sqrt{x-2}$")
ax.set_xlabel("x")
ax.set_ylabel("g(x)")
ax.grid(True, alpha=0.3)

plt.show()

Similarly, use only positive inputs for np.log(x).

Do Not Draw Across a Vertical Asymptote

For h(x) = 1/x, connecting a point just left of zero to a point just right of zero creates a false line across the discontinuity. Plot the two branches separately.

def h(x):
    return 1/x

x_left = np.linspace(-5, -0.05, 400)
x_right = np.linspace(0.05, 5, 400)

fig, ax = plt.subplots(figsize=(7, 4.5))
ax.plot(x_left, h(x_left), color="purple")
ax.plot(x_right, h(x_right), color="purple", label=r"$h(x)=1/x$")

ax.axhline(0, color="black", linewidth=0.8)
ax.axvline(0, color="black", linewidth=0.8, linestyle="--")
ax.set_xlim(-5, 5)
ax.set_ylim(-10, 10)
ax.grid(True, alpha=0.3)
ax.legend()

plt.show()

A Connected Line Is Not Proof of Continuity

plot joins consecutive data points. It does not detect every hole, jump, or asymptote automatically.

2.2.9 Plot a Piecewise Function

p(x) = { x + 2 if x < 1;   x2 if x ≥ 1 } 
def p(x):
    x = np.asarray(x)
    return np.where(x < 1, x + 2, x**2)

x = np.linspace(-4, 4, 500)

fig, ax = plt.subplots(figsize=(7, 4.5))
ax.plot(x, p(x), color="darkorange", linewidth=2)
ax.axhline(0, color="black", linewidth=0.8)
ax.axvline(0, color="black", linewidth=0.8)
ax.set_title("A Piecewise-Defined Function")
ax.set_xlabel("x")
ax.set_ylabel("p(x)")
ax.grid(True, alpha=0.3)

plt.show()

This function has a jump at x = 1. For a mathematically exact endpoint display, mark excluded values with open circles and included values with filled circles:

ax.scatter([1], [3], facecolors="white", edgecolors="darkorange", s=70)
ax.scatter([1], [1], color="darkorange", s=70)

The open circle represents the excluded value from x + 2; the filled circle represents p(1) = 1.

2.2.10 Separate Graphs with Subplots

Subplots are useful when curves have different scales or when overlapping lines would be crowded.

x = np.linspace(-2*np.pi, 2*np.pi, 500)

fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 4))

ax1.plot(x, np.sin(x), color="royalblue")
ax1.set_title(r"$y=\sin(x)$")
ax1.set_xlabel("x")
ax1.grid(True, alpha=0.3)

ax2.plot(x, np.cos(x), color="crimson")
ax2.set_title(r"$y=\cos(x)$")
ax2.set_xlabel("x")
ax2.grid(True, alpha=0.3)

fig.suptitle("Trigonometric Functions")
fig.tight_layout()
plt.show()

plt.subplots(1, 2) creates one row with two Axes. The variables ax1 and ax2 control them separately.

2.2.11 Read Mathematics from a Graph

A graph can help you estimate:

  • domain and range: visible input and output values;
  • intercepts: where the graph meets an axis;
  • sign: where the output is positive, zero, or negative;
  • increasing and decreasing intervals: where outputs rise or fall;
  • local extrema: visible peaks and valleys;
  • symmetry: reflections across an axis or the origin;
  • discontinuities: holes, jumps, or asymptotes; and
  • end behaviour: what appears to happen for large positive or negative inputs.

Graphical Evidence Is Approximate

A graph is excellent for exploration and checking. Exact intercepts, extrema, and limits require algebra, calculus, or a reliable numerical method.

2.2.12 A Reusable Plotting Helper

def plot_function(function, x_min, x_max, title, label):
    x = np.linspace(x_min, x_max, 500)
    y = function(x)

    fig, ax = plt.subplots(figsize=(7, 4.5))
    ax.plot(x, y, linewidth=2, label=label)
    ax.axhline(0, color="black", linewidth=0.8)
    ax.axvline(0, color="black", linewidth=0.8)
    ax.set_xlabel("x")
    ax.set_ylabel("y")
    ax.set_title(title)
    ax.grid(True, alpha=0.3)
    ax.legend()
    plt.show()

def cubic(x):
    return x**3 - 3*x

plot_function(cubic, -3, 3, "A Cubic Function", r"$x^3-3x$")

Passing a function as an argument allows the same plotting code to be reused.

2.2.14 Common Errors

ProblemLikely cause and fix
NameError: plt is not definedRun import matplotlib.pyplot as plt.
The graph is emptyCheck the domain, viewing window, and whether the function produces finite values.
x and y have different sizesCalculate y directly from the same x array.
The curve looks angularIncrease the number of sample points.
A legend does not appearAdd label=... to each curve and call ax.legend().
A false line crosses an asymptote or jumpSplit the domain and plot each continuous branch separately.
A square root or logarithm produces warningsGenerate inputs only from the real-number domain.
Several plots overlap unexpectedlyCreate a new Figure with fig, ax = plt.subplots().

2.2.15 Concept Check

  1. Why do we create an array of inputs before plotting a function?
  2. What is the difference between a Figure and an Axes?
  3. What does increasing the number of sample points change?
  4. Why should 1/x be plotted in two pieces around zero?
  5. What commands set the horizontal and vertical viewing windows?
  6. Why should multiple curves have labels and a legend?
Show suggested answers
  1. The computer needs numerical coordinates at which to evaluate and draw the function.
  2. The Figure is the complete visual object; an Axes is one plotting region inside it.
  3. It improves the plotted approximation but does not change the mathematical function.
  4. The function is undefined at zero, and joining both sides would draw a false segment.
  5. ax.set_xlim and ax.set_ylim.
  6. They identify each curve without relying only on colour.

Section Summary

  • A function graph is constructed from arrays of input and output values.
  • plt.subplots() creates a Figure and one or more Axes.
  • Labels, titles, grids, and legends make a graph interpretable.
  • The viewing window and number of sample points affect what the graph reveals.
  • Multiple curves can show comparisons and approximate intersections.
  • Domains and discontinuities must be handled deliberately.
  • Graphs reveal patterns and motivate the numerical study of limits in Section 2.3.
