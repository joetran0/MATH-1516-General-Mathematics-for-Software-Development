Section 0.2: Installing Python

Part 0: Getting Started with Python

Before Installing Windows macOS Linux Verification Troubleshooting

Learning Objectives

By the end of this section, you should be able to:

  • identify the correct official source for downloading Python;
  • install a stable version of Python on Windows, macOS, or Linux;
  • open a terminal or command-line window;
  • verify the installed Python version;
  • start and exit the interactive Python interpreter; and
  • diagnose several common installation problems.

0.2.1 Before Installing Python

Python consists of the interpreter, which reads and executes Python instructions, and the standard library, which provides many commonly used tools. Installing Python gives your computer the ability to run programs saved in files ending with .py.

Use the Official Python Website

Download Python from python.org/downloads. The download page lists active releases and identifies whether each release is stable, in prerelease testing, receiving bug fixes, or receiving only security updates.

Recommended Version for This Course

Install the latest stable Python 3 release offered on the official download page. As of September 2026, Python 3.14 is the current stable feature series, while Python 3.15 is still a prerelease. Do not install a prerelease, experimental, or free-threaded build for these activities unless you have a specific reason to test it.

Check Whether Python Is Already Installed

Open a terminal and try one of the commands below:

Operating System Command
Windows python --version
Windows alternative py --version
macOS or Linux python3 --version

If the command displays a supported Python 3 version, you may already have what you need. If the command is not found, or it reports an old installation that you do not intend to use, follow the instructions for your operating system.

0.2.2 Installing Python on Windows

Current Python documentation recommends the Python Install Manager. It installs and manages Python runtimes and makes the python and py commands available from a terminal.

Installation Steps

  1. Visit python.org/downloads.
  2. Download the Python Install Manager for Windows. The Microsoft Store version is also an official option.
  3. Open the downloaded installer and select Install.
  4. After installation, open Windows Terminal, PowerShell, or Command Prompt.
  5. Enter python. If no Python runtime is installed yet, the manager can install the current stable release.
  6. Enter python --version to confirm the installation.

A successful version check will look similar to:

Python 3.14.7

Your patch number may be different. For example, both Python 3.14.6 and Python 3.14.7 belong to the same Python 3.14 feature series.

The python and py Commands

For ordinary course work, use python. The py command is useful when several Python versions are installed. You can enter py list to see the runtimes known to the Install Manager.

If Windows Opens the Microsoft Store

Confirm that the Python Install Manager is installed. Then search Windows Settings for Manage app execution aliases and confirm that the aliases for Python are enabled. You can also test whether py works.

0.2.3 Installing Python on macOS

The Python Software Foundation provides a signed and notarized .pkg installer that supports compatible Intel and Apple Silicon Macs.

Installation Steps

  1. Visit Python Releases for macOS.
  2. Choose the latest stable Python 3 release and download the macOS installer package.
  3. Open the downloaded .pkg file.
  4. Follow the installer prompts. The standard installation options are appropriate for this course.
  5. Open the new Python folder in /Applications.
  6. Double-click Install Certificates.command and wait for the completion message.
  7. Open Terminal and enter python3 --version.

A successful version check will look similar to:

Python 3.14.7

Do Not Remove Apple's System Python

Some versions of macOS provide an Apple-controlled /usr/bin/python3 for developer tools. Do not modify or delete that installation. The Python downloaded from python.org can coexist with it, and the standard installer normally configures the newer python3 command for you.

Finding the Python Command

To see which Python installation your terminal is using, enter:

which python3

A python.org installation commonly places a link in /usr/local/bin.

0.2.4 Python on Linux

Most Linux distributions already include Python 3 or provide it through the distribution's package manager. First, open a terminal and enter: 

python3 --version

If Python 3 is available, no additional installation may be necessary. If it is missing, use the instructions provided by your Linux distribution. Common commands include:

Distribution Family Typical Commands
Ubuntu or Debian sudo apt update
sudo apt install python3 python3-pip
Fedora sudo dnf install python3 python3-pip
OpenSUSE sudo zypper install python3 python3-pip

Do Not Replace the System Python

Linux system tools may depend on the Python installation supplied by the distribution. Avoid deleting it or manually replacing /usr/bin/python3. For this introductory course, use the distribution package unless you have a clear reason to maintain another installation.

0.2.5 Verifying the Installation

Step 1: Check the Version

Use the appropriate command:

# Windows
python --version

# macOS or Linux
python3 --version

Step 2: Start Interactive Python

Enter python on Windows or python3 on macOS/Linux.

Python 3.14.7 ...
Type "help", "copyright", "credits" or "license" for more information.
>>>

The >>> symbol is the Python prompt. It means Python is waiting for an instruction.

Step 3: Run a Test Calculation

>>> 2 + 3
5
>>> print("Python is working!")
Python is working!

Step 4: Exit Python

>>> exit()

You should return to the ordinary terminal prompt. On Windows, pressing Ctrl+Z and then Enter also exits. On macOS/Linux, press Ctrl+D.

Installation Check

Confirm that you can complete every item:

  • ☐ Open a terminal or command-line window.
  • ☐ Display a Python 3 version.
  • ☐ Start the Python interpreter.
  • ☐ Calculate 12 ** 2 and obtain 144.
  • ☐ Print your name using print.
  • ☐ Exit the interpreter.

0.2.6 Running a Python File

Open a plain-text editor and create a file named installation_test.py. Enter the following: 

print("My Python installation works.")

x = 6
y = 7
print("The product is", x * y)

Save the file. In a terminal, move to the folder containing the file and run one of the following: 

# Windows
python installation_test.py

# macOS or Linux
python3 installation_test.py

The expected output is:

My Python installation works.
The product is 42

Terminal Folder

The terminal must be working in the folder containing your file, or you must provide the file's complete path. Section 0.3 will introduce coding environments that make creating and running files easier.

0.2.7 Common Installation Problems

Problem What to Check
python is not recognized on Windows Try py. Confirm the Install Manager is installed and its app execution aliases are enabled.
python is not found on macOS/Linux Use python3. These systems commonly reserve or omit the unnumbered command.
The displayed version is not the one expected Use py list on Windows or which python3 on macOS/Linux to identify the selected installation.
The terminal appears stuck at >>> You are inside interactive Python. Enter exit() to return to the terminal.
A file opens as text but does not run Run it from the terminal using python filename.py or python3 filename.py.
You cannot install software on a managed computer Ask the institution's technical support team or use a browser-based environment discussed in Section 0.3.

Section Summary

  • Download Python from the official Python website.
  • Choose the latest stable Python 3 release, not a prerelease build.
  • Windows uses the Python Install Manager and commonly runs Python with python.
  • macOS and Linux commonly run Python with python3.
  • Use --version to verify the selected installation.
  • The >>> prompt indicates that interactive Python is running.
  • Do not remove an operating-system-controlled Python installation.
