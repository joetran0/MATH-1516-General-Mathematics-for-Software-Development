0.3.1 What Is a Coding Environment?

The Python interpreter is the program that executes Python code. A coding environment provides a convenient place to write, organize, run, and debug that code.

Different environments present Python in different ways. Some resemble a traditional text editor, while others divide work into interactive cells. The Python language remains the same, but the workflow changes.

Term Meaning
Interpreter The program that reads and executes Python instructions.
Code editor A text editor with features designed for writing source code.
IDE An integrated development environment combining editing, execution, debugging, and project tools.
Notebook An interactive document containing separate cells for code, text, mathematics, and output.
Terminal A text-based interface for entering commands and running programs.

The Environment Does Not Replace Python

Visual Studio Code does not contain the Python interpreter by itself. Similarly, a notebook interface still requires a Python runtime. The environment helps you interact with the interpreter.

0.3.2 Comparing the Main Options

Environment Installation Best Use Main Limitation
IDLE Usually included with Python First programs and simple scripts Limited project and notebook features
Visual Studio Code Install VS Code and its Python extension Organized files, larger programs, and debugging Requires more initial configuration
JupyterLab Install locally as a Python package Mathematics, data analysis, graphs, and explanations Cell order can create hidden state
Google Colab No local installation; runs in a browser Quick tutorial activities and shared notebooks Requires internet and uses temporary runtimes

There is no universally best environment. The correct choice depends on the task, the available computer, and how the work will be submitted or shared.

Environment Used in MATH 1516 Tutorials

Unless an activity says otherwise, the coding activities for these tutorials will use Google Colab. This gives every student the same notebook-style environment and avoids differences between local Python installations.

0.3.3 IDLE

IDLE is Python's Integrated Development and Learning Environment. It provides both a Python Shell for interactive commands and an Editor for complete .py files. It is cross-platform and is commonly included with the official Python installation.

Opening IDLE

  • Windows: open the Start menu and search for IDLE.
  • macOS: open the Python folder in Applications and select IDLE.
  • Terminal: try python -m idlelib on Windows or python3 -m idlelib on macOS/Linux.

The Shell and the Editor

The Shell displays the >>> prompt and is useful for testing one instruction at a time. The Editor is used for programs that contain several lines and need to be saved.

Run a File in IDLE

  1. Open IDLE.
  2. Select File > New File.
  3. Enter the code shown below.
  4. Select File > Save As and save it as environment_test.py.
  5. Select Run > Run Module.
  6. Read the output in the Shell window.
course = "MATH 1516"
number_of_parts = 4

print(course)
print("Mathematical parts:", number_of_parts)

The expected output is:

MATH 1516
Mathematical parts: 4

IDLE is a good choice when:

  • you are learning the difference between the Shell and a saved program;
  • you want a simple environment with few distractions; or
  • you want to confirm that the standard Python installation is working.

0.3.4 Visual Studio Code

Visual Studio Code, usually called VS Code, is a general code editor. For Python development, three separate components work together:

  1. VS Code provides the editor and workspace.
  2. The Microsoft Python extension adds Python-aware editing, running, and debugging features.
  3. The Python interpreter executes the code.

Installing VS Code Does Not Install Python

Complete Section 0.2 first. The Python extension connects VS Code to an existing interpreter; it does not include the interpreter itself.

Basic VS Code Setup

  1. Download VS Code from code.visualstudio.com.
  2. Install and open VS Code.
  3. Open the Extensions view.
  4. Search for Python and install the extension published by Microsoft.
  5. Create or open a folder for your MATH 1516 activities.
  6. Create a file named environment_test.py.
  7. Select the Python interpreter when prompted.

Selecting the Interpreter

Open the Command Palette and choose Python: Select Interpreter. Select the stable Python 3 installation from Section 0.2. The selected version normally appears in the status bar.

Wrong Interpreter, Missing Package

A computer can contain several Python installations. If code works in one terminal but VS Code reports that a package is missing, first check which interpreter VS Code has selected.

Running a Python File

Enter the following code and save the file:

x = 5
y = 12
distance = (x ** 2 + y ** 2) ** 0.5

print("Distance:", distance)

Select the triangular Run Python File button in the top-right corner of the editor. VS Code opens an integrated terminal and displays: 

Distance: 13.0

VS Code is a good choice when:

  • you want to organize several Python files in folders;
  • you are developing a longer program;
  • you want autocompletion and debugging tools; or
  • you want an environment commonly used in software development.

0.3.5 JupyterLab and Jupyter Notebook

A Jupyter notebook is divided into cells. A code cell contains executable Python, while a Markdown cell contains headings, explanations, links, or mathematical notation. Output appears directly below the cell that produced it.

This format is particularly useful when a mathematical explanation, a calculation, and a graph need to appear together.

Installing JupyterLab

In a terminal, enter:

# Windows
python -m pip install jupyterlab

# macOS or Linux
python3 -m pip install jupyterlab

After installation, start JupyterLab with:

jupyter lab

JupyterLab normally opens in your web browser, but the Python process runs on your own computer. Keep the terminal window open while JupyterLab is running.

Working with Cells

  1. Create a new Python notebook.
  2. Enter Python code in a code cell.
  3. Run the cell using the Run button or Shift+Enter.
  4. Add a Markdown cell to explain the result.
  5. Save the notebook. Notebook filenames end with .ipynb.
values = [2, 4, 6, 8]
average = sum(values) / len(values)
average

The output 5.0 appears beneath the cell.

Notebook Cells Can Be Run Out of Order

A notebook remembers values created by previously executed cells. Running cells in a different order can produce confusing results. Before submitting a notebook, restart the kernel and run all cells from top to bottom.

Jupyter is a good choice when:

  • you want to combine mathematics, explanations, code, and graphs;
  • you want to test a calculation one step at a time;
  • you are exploring data; or
  • you want a record of both the code and its output.

0.3.6 Google Colab

Google Colab is a hosted Jupyter Notebook service. It runs in a web browser and requires no local Python setup. Notebooks can be stored in Google Drive, downloaded as .ipynb files, and shared with other users.

Create a Colab Notebook

  1. Visit colab.research.google.com.
  2. Sign in with a Google account if prompted.
  3. Create a new notebook.
  4. Rename the notebook, for example MATH1516_Environment_Test.ipynb.
  5. Enter the code below in the first code cell.
  6. Run the cell using the play button.
numbers = [1, 3, 5, 7, 9]

print("Count:", len(numbers))
print("Sum:", sum(numbers))
print("Mean:", sum(numbers) / len(numbers))

The expected output is:

Count: 5
Sum: 25
Mean: 5.0

Colab Runtimes Are Temporary

Your notebook document can be saved, but the remote runtime may disconnect or reset. Variables, uploaded temporary files, and packages installed only in that runtime may disappear. Run the notebook from the beginning after a reset.

Colab is a good choice when:

  • you cannot install software on the computer you are using;
  • you want to begin an activity quickly during a tutorial;
  • you want to share a notebook; or
  • you are working on more than one computer.

0.3.7 Recommended Workflow for MATH 1516

Course Recommendation: Google Colab

Use Google Colab for the MATH 1516 tutorial coding activities. Students can open a shared notebook in a browser, make their own copy, run individual cells, and save the completed notebook without configuring a local Python editor.

IDLE, Visual Studio Code, and local Jupyter remain useful alternatives for independent practice. Visual Studio Code is especially helpful for students who later want to organize larger software projects using ordinary .py files.

Standard Tutorial Routine

  1. Open the Colab link provided for the activity.
  2. Select File > Save a copy in Drive.
  3. Rename the copy using the requested filename.
  4. Read each explanation before running its code cell.
  5. Predict the output, then run the cell.
  6. Complete the marked exercises in your own copy.
  7. Before finishing, select Runtime > Restart session and run all when available, or restart and run the cells from top to bottom.

Activity: Compare Two Environments

  1. Run the code below in two different environments.
  2. Record how you created, ran, and saved the program in each environment.
  3. Identify one advantage and one disadvantage of each environment.
  4. Choose which environment you would prefer for future tutorial activities.
n = 10
total = n * (n + 1) / 2

print("The sum from 1 to", n, "is", total)

0.3.8 File Types and Saving Your Work

File Type Purpose
.py A plain Python source-code file, commonly used in IDLE and VS Code
.ipynb A notebook containing cells, outputs, and document metadata
.csv A plain-text data table that Python can read using packages such as pandas
  • Create one folder for MATH 1516 coding activities.
  • Use descriptive filenames such as section_1_1_matrices.py.
  • Avoid filenames such as numpy.py, random.py, or pandas.py, because they can conflict with package names.
  • Save your work before running it.
  • For notebooks, restart and run all cells before submitting or sharing.

  2. Why are notebooks useful for mathematical work?
  3. What problem can occur when notebook cells are executed out of order?
  4. Which environment would you choose on a computer where you cannot install software?
  5. Why must VS Code have a Python interpreter selected?
Show suggested answers
  1. Python is the language and interpreter; VS Code is an editor that can connect to the interpreter.
  2. They combine explanations, mathematical notation, code, and output in one document.
  3. The displayed output may depend on hidden values created by previously executed cells.
  4. Google Colab, because it runs in a browser and requires no local Python setup.

  • A coding environment helps you write, run, organize, and debug Python code.
