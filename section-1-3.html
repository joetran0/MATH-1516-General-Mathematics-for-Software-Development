1.3.1 Begin in Google Colab

Open a new Google Colab notebook and run this setup cell:

import numpy as np

NumPy is already installed in Colab, so no package installation is required.

1.3.2 Addition and Subtraction

Matrices can be added or subtracted only when they have the same order. The operation is performed entry by entry.

A = np.array([
    [1, 2],
    [3, 4]
])

B = np.array([
    [5, 1],
    [2, 6]
])

print(A + B)
print(A - B)

The results are:

[[6 3]
 [5 10]]

[[-4  1]
 [ 1 -2]]

Shape Check

Before adding or subtracting, compare A.shape and B.shape. For ordinary matrix addition, the shapes must match.

1.3.3 Scalar Multiplication

A scalar is a single number. Multiplying a matrix by a scalar multiplies every entry by that number.

A = np.array([
    [ 1, -2],
    [ 3,  4]
])

print(3 * A)
[[ 3 -6]
 [ 9 12]]

Scalar multiplication does not change the order of a matrix.

1.3.4 Elementwise Operations

For NumPy arrays, * multiplies corresponding entries. This is called elementwise multiplication.

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])

print(A * B)
[[ 5 12]
 [21 32]]

Other elementwise operations include A / B and A ** 2.

* Is Not Matrix Multiplication

Use * for entry-by-entry multiplication. Use @ for a matrix product. Confusing these operators is one of the most common NumPy errors in linear algebra.

1.3.5 The Transpose

The transpose of a matrix interchanges its rows and columns. If A has order m × n, then AT has order n × m.

A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

print(A.T)
print("A shape:", A.shape)
print("A.T shape:", A.T.shape)
[[1 4]
 [2 5]
 [3 6]]
A shape: (2, 3)
A.T shape: (3, 2)

Transposing twice returns the original matrix: (A.T).T equals A.

Transposing a 1-D Array

If v.shape is (3,), then v.T still has shape (3,). Use v.reshape(3, 1) when you need an explicit 3 × 1 column matrix.

1.3.6 Vector Dot Products

The dot product multiplies corresponding vector entries and then adds the products.

For u = [1, 2, 3] and v = [4, 5, 6]:

u · v = 1(4) + 2(5) + 3(6) = 32.

u = np.array([1, 2, 3])
v = np.array([4, 5, 6])

print(u @ v)
print(np.dot(u, v))

Both instructions display 32.

1.3.7 Matrix-Vector Products

An m × n matrix can multiply a vector of length n. The result is a vector of length m.

A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

x = np.array([2, 0, -1])

print(A @ x)
[-1  2]

Each result entry is the dot product of one row of A with x.

1.3.8 Matrix-Matrix Products

Suppose A has order m × n and B has order n × p. Then AB is defined and has order m × p.

Dimension Rule

  1. Write the orders side by side: (m × n)(n × p).
  2. Check that the inner dimensions match.
  3. The outer dimensions give the result: m × p.

Worked Example

A = np.array([
    [1, 2, 3],
    [4, 5, 6]
])

B = np.array([
    [1, 2],
    [0, 1],
    [2, 0]
])

C = A @ B

print(C)
print(C.shape)
[[ 7  4]
 [16 13]]
(2, 2)

For example, the upper-left entry is the dot product of row 1 of A and column 1 of B: 1(1) + 2(0) + 3(2) = 7.

1.3.9 Order Matters

Matrix multiplication is generally not commutative. Even when both products exist, AB and BA may be different.

A = np.array([[1, 2], [0, 1]])
B = np.array([[2, 0], [3, 1]])

print("A @ B:")
print(A @ B)

print("B @ A:")
print(B @ A)
A @ B:
[[8 2]
 [3 1]]
B @ A:
[[2 4]
 [3 7]]

In other examples, one product may be defined while the reverse product is not.

1.3.10 Identity and Powers

For a square matrix A and a matching identity matrix I, AI = IA = A.

A = np.array([[1, 2], [3, 4]])
I = np.eye(2, dtype=int)

print(A @ I)
print(I @ A)

A matrix square means a matrix product:

matrix_square = A @ A
entry_squares = A ** 2

print(matrix_square)
print(entry_squares)

Two Different Meanings

A @ A computes A2 in linear algebra. A ** 2 merely squares each entry.

1.3.11 Checking Compatibility in Code

def can_multiply(A, B):
    """Return True when two 2-D arrays can form A @ B."""
    return (
        A.ndim == 2
        and B.ndim == 2
        and A.shape[1] == B.shape[0]
    )

A = np.zeros((2, 3))
B = np.zeros((3, 4))

print(can_multiply(A, B))
print(can_multiply(B, A))

The output is True followed by False. If multiplication is possible, the product shape is (A.shape[0], B.shape[1]).

1.3.14 Concept Check

  1. What condition is required to add two matrices?
  2. What is the difference between A * B and A @ B?
  3. If A.shape == (4, 3), what is A.T.shape?
  4. Can a 3 × 5 matrix multiply a 5 × 2 matrix? What is the product order?
  5. Can a 3 × 5 matrix multiply a 3 × 2 matrix?
  6. Why might A @ B differ from B @ A?
Show suggested answers
  1. They must have the same order.
  2. * is elementwise; @ forms a matrix product.
  3. (3, 4).
  4. Yes. The product is 3 × 2.
  5. No, because the inner dimensions 5 and 3 do not match.
  6. Matrix multiplication combines rows and columns in an order-dependent way; it is generally not commutative.

1.3.15 Practice Exercises

  1. Create two 3 × 3 matrices and calculate their sum and difference.
  2. Multiply a 2 × 4 matrix by the scalar 5.
  3. For two compatible arrays, compare elementwise and matrix multiplication.
  4. Create a 2 × 5 matrix and print its transpose and both shapes.
  5. Calculate the dot product of [2, -1, 3] and [4, 5, 0] by hand and with NumPy.
  6. Create matrices with shapes (3, 2) and (2, 4). Predict and verify the product shape.
  7. Find square matrices A and B for which AB is not equal to BA.
  8. Write a function that returns the expected product shape or None if multiplication is impossible.
Show sample solution for Exercise 8 
def product_shape(A, B):
    if A.ndim != 2 or B.ndim != 2:
        return None
    if A.shape[1] != B.shape[0]:
        return None
    return (A.shape[0], B.shape[1])

Section Summary

  • Matrices must have the same order for addition or subtraction.
  • Scalar multiplication applies the scalar to every entry.
  • For NumPy arrays, * is elementwise multiplication and @ is matrix multiplication.
  • Transposing an m × n matrix produces an n × m matrix.
  • An m × n matrix times an n × p matrix produces an m × p matrix.
  • Matrix multiplication is generally not commutative.
  • A @ A and A ** 2 represent different calculations.
