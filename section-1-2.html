Learning Objectives

By the end of this section, you should be able to:

  • state the order of a matrix using the form m by n;
  • interpret the notation aij;
  • translate between mathematical indexing and NumPy indexing;
  • extract rows, columns, and diagonal entries;
  • distinguish square, rectangular, row, and column matrices;
  • identify zero, identity, diagonal, scalar, triangular, and symmetric matrices;
  • construct common special matrices using NumPy; and
  • write short tests that classify a matrix from its entries and shape.

1.2.1 Matrix Order

A matrix is a rectangular arrangement of entries organized into rows and columns. If a matrix has m rows and n columns, its order is m by n, written m × n. 

A = np.array([
    [2, -1, 4],
    [0,  3, 5]
])

The matrix A has two rows and three columns. It is a 2 × 3 matrix. 

rows, columns = A.shape

print("Rows:", rows)
print("Columns:", columns)
print(f"Order: {rows} by {columns}")

Rows Come First

A 2 × 3 matrix has two rows and three columns. It does not have three rows and two columns. NumPy follows the same order in A.shape == (2, 3).

Total Number of Entries

An m × n matrix contains mn entries. The 2 × 3 matrix above contains 6 entries. 

print(A.size)
print(rows * columns)

Both instructions display 6.

1.2.2 Matrix Entries and Subscripts

The entry in row i and column j of a matrix A is denoted by aij. The row subscript appears first, followed by the column subscript.

For the matrix:

A = np.array([
    [ 2, -1, 4],
    [ 0,  3, 5],
    [-2,  6, 1]
])
Mathematical Entry Meaning Value NumPy Code
a11 Row 1, column 1 2 A[0, 0]
a13 Row 1, column 3 4 A[0, 2]
a22 Row 2, column 2 3 A[1, 1]
a32 Row 3, column 2 6 A[2, 1]

Mathematics Starts at 1; NumPy Starts at 0

Mathematical matrix subscripts normally begin at 1. NumPy array indices begin at 0. Therefore, the mathematical entry aij is accessed with A[i - 1, j - 1].

A Reusable Entry Function

def matrix_entry(A, i, j):
    """Return mathematical entry a_ij using 1-based indices."""
    return A[i - 1, j - 1]

print(matrix_entry(A, 3, 2))

The output is 6.

1.2.3 Rows and Columns

A row is a horizontal sequence of entries, while a column is a vertical sequence. NumPy uses a colon to select every position along an axis. 

A = np.array([
    [ 2, -1, 4],
    [ 0,  3, 5],
    [-2,  6, 1]
])

row_2 = A[1, :]
column_3 = A[:, 2]

print("Second row:", row_2)
print("Third column:", column_3)

The output is:

Second row: [0 3 5]
Third column: [4 5 1]

Preserving Row or Column Shape

row_2_matrix = A[1:2, :]
column_3_matrix = A[:, 2:3]

print(row_2_matrix.shape)
print(column_3_matrix.shape)

The shapes are (1, 3) and (3, 1). Using a single index instead produces a 1-D array of shape (3,).

Selection Resulting Shape for a 3 × 3 Matrix
A[1, :] (3,)
A[1:2, :] (1, 3)
A[:, 2] (3,)
A[:, 2:3] (3, 1)

1.2.4 Basic Matrix Classifications

Type Definition Example Shape
Rectangular matrix A matrix whose number of rows differs from its number of columns (2, 3)
Square matrix A matrix with the same number of rows and columns (3, 3)
Row matrix A matrix containing exactly one row (1, 4)
Column matrix A matrix containing exactly one column (4, 1) 
def is_square(A):
    """Return True when A is a square 2-D array."""
    return A.ndim == 2 and A.shape[0] == A.shape[1]

M = np.array([[1, 2], [3, 4]])
N = np.array([[1, 2, 3], [4, 5, 6]])

print(is_square(M))
print(is_square(N))

The output is True followed by False.

1.2.5 Main and Secondary Diagonals

In a square matrix, the main diagonal runs from the upper-left entry to the lower-right entry. Its entries have equal row and column subscripts: a11, a22, and so on. 

A = np.array([
    [2, 4, 6],
    [1, 3, 5],
    [7, 8, 9]
])

main_diagonal = np.diag(A)
print(main_diagonal)

The output is [2 3 9].

Trace of a Square Matrix

The trace is the sum of the main diagonal entries. NumPy calculates it using np.trace(). 

print(np.trace(A))

The output is 14.

Secondary Diagonal

The secondary diagonal runs from the upper-right entry to the lower-left entry. One way to extract it is to reverse the column order and then take the main diagonal. 

secondary_diagonal = np.diag(np.fliplr(A))
print(secondary_diagonal)

The output is [6 3 7].

np.diag() Has Two Related Uses

Given a 2-D array, it extracts the main diagonal. Given a 1-D array, it creates a diagonal matrix containing those values.

1.2.6 Zero and Identity Matrices

Zero Matrix

A zero matrix has zero in every entry.

Z = np.zeros((3, 4), dtype=int)
print(Z)

Identity Matrix

The identity matrix is square, has 1 on the main diagonal, and has 0 everywhere else. It is commonly denoted by I. 

I = np.eye(3, dtype=int)
print(I)

The output is:

[[1 0 0]
 [0 1 0]
 [0 0 1]]

The identity matrix plays a role for matrix multiplication similar to the role of the number 1 in ordinary multiplication. That property will be examined in Section 1.3.

1.2.7 Diagonal and Scalar Matrices

A diagonal matrix is a square matrix whose entries outside the main diagonal are all zero. 

D = np.diag([2, -1, 5])
print(D)

The output is:

[[ 2  0  0]
 [ 0 -1  0]
 [ 0  0  5]]

A scalar matrix is a diagonal matrix whose diagonal entries are all equal. For example: 

S = 4 * np.eye(3, dtype=int)
print(S)

Every identity matrix is a scalar matrix with scalar 1. Every scalar matrix is diagonal, but not every diagonal matrix is scalar.

Testing Whether a Matrix Is Diagonal

def is_diagonal(A):
    """Return True when A is a square diagonal matrix."""
    if A.ndim != 2 or A.shape[0] != A.shape[1]:
        return False

    diagonal_part = np.diag(np.diag(A))
    return np.array_equal(A, diagonal_part)

print(is_diagonal(D))

1.2.8 Triangular Matrices

An upper triangular matrix has zero entries below the main diagonal. A lower triangular matrix has zero entries above the main diagonal. 

U = np.array([
    [2, 4, 1],
    [0, 3, 5],
    [0, 0, 7]
])

L = np.array([
    [2, 0, 0],
    [4, 3, 0],
    [1, 5, 7]
])

NumPy can extract triangular portions of a matrix:

A = np.array([
    [2, 4, 1],
    [6, 3, 5],
    [8, 9, 7]
])

upper_part = np.triu(A)
lower_part = np.tril(A)

print(upper_part)
print(lower_part)

Testing Triangular Structure

def is_upper_triangular(A):
    """Return True when A is a square upper triangular matrix."""
    return is_square(A) and np.array_equal(A, np.triu(A))

def is_lower_triangular(A):
    """Return True when A is a square lower triangular matrix."""
    return is_square(A) and np.array_equal(A, np.tril(A))

Diagonal Matrices Are Both

A diagonal matrix has zeros both above and below its main diagonal. Therefore, every diagonal matrix is both upper triangular and lower triangular.

1.2.9 Symmetric Matrices

A square matrix is symmetric when entries reflected across the main diagonal are equal. In notation, aij = aji for every pair of indices. 

A = np.array([
    [2, 1, 4],
    [1, 3, 5],
    [4, 5, 7]
])

The transpose A.T interchanges rows and columns. A symmetric matrix equals its transpose. 

print(A.T)
print(np.array_equal(A, A.T))

Numerical Comparison

For arrays produced by floating-point calculations, small rounding errors can occur. Use np.allclose() when approximate equality is appropriate. 

def is_symmetric(A):
    """Return True when A is approximately symmetric."""
    return is_square(A) and np.allclose(A, A.T)

print(is_symmetric(A))

Symmetric Matrices Must Be Square

A rectangular matrix and its transpose have different shapes, so they cannot be equal as matrices.

1.2.10 Classification Relationships

Some matrix types form nested categories:

  • Every identity matrix is a scalar matrix.
  • Every scalar matrix is a diagonal matrix.
  • Every diagonal matrix is both upper and lower triangular.
  • Every diagonal matrix is symmetric.
  • A zero square matrix belongs to all of these categories except identity.
Matrix Square Diagonal Triangular Symmetric
Identity matrix Yes Yes Upper and lower Yes
Scalar matrix Yes Yes Upper and lower Yes
General upper triangular matrix Yes Not necessarily Upper Not necessarily
General symmetric matrix Yes Not necessarily Not necessarily Yes

1.2.12 Common Errors

Problem Cause Correction
Reversing matrix order Columns were counted before rows. Use rows first: A.shape == (rows, columns).
Wrong entry selected Mathematical subscripts were used directly as NumPy indices. Access aij with A[i - 1, j - 1].
Column has shape (m,) A single column index removed one dimension. Use A[:, j:j+1] to preserve shape (m, 1).
Symmetry test fails after calculations Small floating-point differences are present. Use np.allclose(A, A.T) when approximate comparison is intended.
Rectangular matrix called diagonal Only off-diagonal zeros were considered. Under the course definition, diagonal matrices must also be square.

Section Summary

  • An m × n matrix has m rows, n columns, and mn entries.
  • The mathematical entry aij corresponds to A[i - 1, j - 1] in NumPy.
  • The main diagonal contains entries whose row and column indices are equal.
  • Square matrices have equal numbers of rows and columns.
  • Identity, scalar, and diagonal matrices form nested special classes.
  • A diagonal matrix is both upper triangular and lower triangular.
  • A symmetric matrix equals its transpose.
  • np.diag(), np.eye(), np.triu(), and np.tril() help construct or inspect special matrices.
