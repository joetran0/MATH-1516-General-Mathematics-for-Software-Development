0.4.1 What Is a Python Package?

Python contains many useful built-in features, but no single programming language includes every possible tool. A package is a collection of reusable Python code that adds features to Python. Packages can provide tools for matrices, graphs, symbolic algebra, data tables, statistics, probability, and much more.

Python tools are commonly grouped into three categories:

Category Description Example
Built-in feature Available immediately without an import statement. print(), len(), sum()
Standard library Installed with Python, but imported when needed. math, random, statistics
Third-party package Developed separately and installed when needed. numpy, matplotlib, sympy

Installing and Importing Are Different

Installing places a package in a Python environment. Importing makes that installed package available to the current program or notebook session. 

# Installation command: normally run once for an environment
%pip install numpy

# Python instruction: run in each new notebook or program
import numpy as np

A Package Usually Needs Only One Installation

You do not normally reinstall a package every time you use it. You do, however, import it in each new program or notebook session. Google Colab is a special case because its temporary runtime can be replaced or reset.

Package Typical Import Use in This Course

Why Use Short Names?

The names np, plt, sp, and pd are widely used conventions. An alias makes later code shorter while still showing which package provides a function.

0.4.3 Recommended Method: Google Colab

Try the Import First

In Google Colab, begin by importing the package. Many commonly used packages are already installed. Install a package only if the import fails or an activity asks for a specific package or version.

Standard Colab Workflow

  1. Open the activity notebook.
  2. Run the import cell near the beginning of the notebook.
  3. If the import works, continue with the activity.
  4. If you see ModuleNotFoundError, add an installation cell.
  5. Run %pip install package_name.
  6. Run the import cell again.
  7. Restart the runtime only if Colab or the installer tells you to do so.

The Standard Import Cell

The following cell imports the main course packages. A tutorial notebook may import only the packages required for that activity. 

import numpy as np
import matplotlib.pyplot as plt
import sympy as sp
import pandas as pd
from scipy import stats

print("Packages imported successfully.")

If the cell runs without an error, the packages are ready to use.

Installing a Missing Package

In a Colab or Jupyter code cell, replace package_name with the actual package name: 

%pip install package_name

For example, to install SymPy:

%pip install sympy

Several packages can be installed in one command:

%pip install numpy matplotlib sympy pandas scipy

Why Use %pip in a Notebook?

The percent sign marks an IPython command. In Jupyter and Colab, %pip runs the installer for the current notebook kernel. This reduces the chance of installing a package into a different Python environment.

Colab Runtimes Are Temporary

A custom package installed during one Colab session may disappear after the runtime resets. Keep required installation cells near the top of the notebook so the activity can be reproduced later or by another student.

Installing a Specific Version

Occasionally, an activity may require one exact version. Use two equals signs between the package name and version number: 

%pip install "package_name==1.2.3"

Do not select an older version without a reason. Use the version stated in the activity, if one is provided.

0.4.4 Testing the Course Packages

An import confirms that Python can find a package. A small calculation gives stronger evidence that its main features are working.

NumPy: Create a Matrix

import numpy as np

A = np.array([[1, 2],
              [3, 4]])

print(A)
print("Shape:", A.shape)

The matrix has two rows and two columns, so its shape is (2, 2).

Matplotlib: Draw a Line

import matplotlib.pyplot as plt

x = [0, 1, 2, 3]
y = [0, 1, 4, 9]

plt.plot(x, y, marker="o")
plt.xlabel("x")
plt.ylabel("x squared")
plt.title("A Simple Plot")
plt.grid(True)
plt.show()

A line graph should appear directly below the cell in Colab.

SymPy: Differentiate an Expression

import sympy as sp

x = sp.symbols("x")
f = x**3 + 2*x
derivative = sp.diff(f, x)

print(derivative)

The output is 3*x**2 + 2.

pandas: Create a Data Table

import pandas as pd

data = {
    "Tutorial": [1, 2, 3],
    "Score": [8, 10, 9]
}

table = pd.DataFrame(data)
print(table)
print("Mean score:", table["Score"].mean())

The mean score is 9.0.

SciPy: Calculate a Binomial Probability

from scipy import stats

# Probability of exactly 3 successes in 5 trials when p = 0.5
probability = stats.binom.pmf(3, n=5, p=0.5)
print(probability)

The output is 0.3125.

0.4.5 Checking Package Versions

Version numbers are useful when diagnosing a problem or reproducing an activity. Most packages make their version available through __version__. 

import numpy as np
import matplotlib
import sympy as sp
import pandas as pd
import scipy

print("NumPy:", np.__version__)
print("Matplotlib:", matplotlib.__version__)
print("SymPy:", sp.__version__)
print("pandas:", pd.__version__)
print("SciPy:", scipy.__version__)

Your version numbers may differ from those shown by another student. This is usually acceptable unless the activity requires a particular version.

0.4.6 Optional Local Installation

Google Colab is recommended for the tutorial activities. If you choose to work locally, install packages into the same Python environment used by your editor or notebook.

Windows

py -m pip install numpy matplotlib sympy pandas scipy

macOS or Linux

python3 -m pip install numpy matplotlib sympy pandas scipy

To check that pip is connected to Python:

# Windows
py -m pip --version

# macOS or Linux
python3 -m pip --version

Why Use python -m pip?

A computer may contain more than one Python installation. Running pip through a specific Python command makes it clearer which interpreter receives the package.

Virtual Environments

A virtual environment is an isolated Python environment for one project. It keeps a project's packages separate from the computer's system installation. Virtual environments are useful for larger projects, but they are not required when completing these tutorials in Google Colab.

Avoid Administrator Installation Unless Required

Do not add sudo or run a terminal as administrator merely to install a package. A user installation or virtual environment is usually safer. On a managed school or workplace computer, use Google Colab or ask the system administrator for assistance.

0.4.7 Common Errors and Solutions

Problem Likely Cause Suggested Action
ModuleNotFoundError The package is not installed in the current environment, or its name is misspelled. Check the spelling, run %pip install package_name, and try the import again.
SyntaxError on an installation command A shell-style command was entered as ordinary Python. In Colab, place %pip install ... in its own code cell.
Installation succeeds but import still fails The notebook may need a restart, or a local editor may be using a different interpreter. Follow any restart message. Locally, confirm the selected Python interpreter.
NameError: name 'np' is not defined The import cell was not run, or a different alias was used. Run import numpy as np before using np.
A package disappears from Colab The temporary runtime was reset or replaced. Run the notebook's installation and import cells again.
An import name differs from the install name Some projects use different package and module names. Use the installation and import instructions provided by the package.

Do Not Name Your File After a Package

A file named numpy.py, pandas.py, sympy.py, or scipy.py can hide the real package from Python. Give your own files descriptive names such as matrix_activity.py.
