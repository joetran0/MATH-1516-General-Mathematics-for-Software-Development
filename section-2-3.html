Learning Objectives

By the end of this section, you should be able to:

  • interpret a limit as nearby function behaviour;
  • distinguish f(a) from the limit as x approaches a;
  • generate inputs approaching a point from the left and right;
  • use numerical tables to estimate finite and infinite limits;
  • compare one-sided limits to decide whether a two-sided limit exists;
  • investigate limits as x tends to positive or negative infinity;
  • recognize oscillation and other evidence that a limit does not exist; and
  • explain why numerical evidence supports—but does not prove—a limit.

import numpy as np

NumPy will generate inputs and evaluate functions. Matplotlib will help us compare the numerical evidence with a graph.

2.3.2 What Does a Limit Describe?

limx→a f(x) = L

This notation says that f(x) approaches L when x approaches a. It describes the behaviour near a, not necessarily the value at a.

ExpressionQuestion
f(a)What is the function's value exactly at x = a?
limx→a f(x)What value do the outputs approach when the inputs get close to a?

Do Not Substitute Too Early

Direct substitution is useful for continuous functions, but a limit may exist even when the original formula is undefined at the point.

2.3.3 Build a Two-Sided Limit Table

Consider

f(x) = (x2 − 4)/(x − 2).

Substituting x = 2 gives 0/0, so the formula is undefined there. We can evaluate it at nearby inputs instead.

def f(x):
    return (x**2 - 4) / (x - 2)

left_x = np.array([1.9, 1.99, 1.999, 1.9999])
right_x = np.array([2.1, 2.01, 2.001, 2.0001])

print("Approaching from the left")
for x in left_x:
    print(f"x = {x:.4f}, f(x) = {f(x):.6f}")

print("Approaching from the right")
for x in right_x:
    print(f"x = {x:.4f}, f(x) = {f(x):.6f}")

Both sides approach 4, so the numerical evidence suggests

limx→2 (x2 − 4)/(x − 2) = 4.

Indeed, for x ≠ 2 the expression simplifies to x + 2. The graph is the line y = x + 2 with a hole at (2, 4).

2.3.4 Generate Approaching Inputs Systematically

Instead of typing every input, define shrinking positive distances from the target point.

a = 2
distances = np.geomspace(1e-1, 1e-6, 6)

left_x = a - distances
right_x = a + distances

print("distance       left x       f(left)      right x      f(right)")
for d, xl, xr in zip(distances, left_x, right_x):
    print(f"{d:8.1e}  {xl:12.8f}  {f(xl):12.8f}  "
          f"{xr:12.8f}  {f(xr):12.8f}")

np.geomspace(1e-1, 1e-6, 6) produces distances 10−1, 10−2, …, 10−6. Each distance is one-tenth of the previous one.

Numerical Limit Workflow

  1. Identify the target input a.
  2. Choose shrinking positive distances.
  3. Evaluate at a − distance and a + distance.
  4. Look for stable output patterns on both sides.
  5. Compare the table with a graph.
  6. State the conclusion as an estimate, not a proof.

2.3.6 Direct Substitution for Continuous Functions

Polynomials, exponential functions, and trigonometric functions are continuous throughout their usual domains. For such a function, substitution often gives the limit directly.

def g(x):
    return x**3 - 2*x + 1

a = -1
print(g(a))   # 2
limx→−1 (x3 − 2x + 1) = 2.

A numerical table can confirm the expected behaviour, but it is unnecessary for every continuous formula.

2.3.7 One-Sided Limits

The left-hand limit uses inputs less than a; the right-hand limit uses inputs greater than a.

limx→a− f(x)   and   limx→a+ f(x)

A finite two-sided limit exists only when the two one-sided limits exist and are equal.

Example: A Jump Discontinuity

p(x) = { x + 2 if x < 1;   x2 if x ≥ 1 } 
def p(x):
    x = np.asarray(x)
    return np.where(x < 1, x + 2, x**2)

distances = np.geomspace(1e-1, 1e-6, 6)
left_x = 1 - distances
right_x = 1 + distances

print(p(left_x))
print(p(right_x))

The left outputs approach 3, while the right outputs approach 1. Therefore the two-sided limit at x = 1 does not exist.

The Function Value Does Not Decide the Limit

Here p(1) = 1, but the unequal one-sided limits are what make the two-sided limit fail to exist.

2.3.8 Infinite Limits and Vertical Asymptotes

Consider q(x) = 1/(x − 2)2. As x approaches 2 from either side, the denominator becomes a small positive number.

def q(x):
    return 1 / (x - 2)**2

distances = np.geomspace(1e-1, 1e-5, 5)
left_x = 2 - distances
right_x = 2 + distances

for xl, xr in zip(left_x, right_x):
    print(f"{xl:.5f}  {q(xl):12.2f}    {xr:.5f}  {q(xr):12.2f}")

The outputs grow without bound on both sides. We write

limx→2 1/(x − 2)2 = +∞.

This describes unbounded behaviour; +∞ is not an ordinary real-number output. The line x = 2 is a vertical asymptote.

Opposite Infinite Behaviour

For r(x) = 1/(x − 2), the left side tends to −∞ and the right side tends to +∞. The two-sided limit therefore does not exist.

def r(x):
    return 1 / (x - 2)

print(r(left_x))
print(r(right_x))

2.3.9 Limits at Infinity

A limit at infinity describes long-term behaviour as the magnitude of the input becomes large.

s(x) = (3x2 + 1)/(x2 − 4) 
def s(x):
    return (3*x**2 + 1) / (x**2 - 4)

positive_x = np.array([10, 100, 1000, 10000], dtype=float)
negative_x = -positive_x

for x in positive_x:
    print(f"x = {x:8.0f}, s(x) = {s(x):.10f}")

for x in negative_x:
    print(f"x = {x:8.0f}, s(x) = {s(x):.10f}")

The outputs approach 3 in both directions, suggesting

limx→∞ s(x) = 3   and   limx→−∞ s(x) = 3.

The line y = 3 is a horizontal asymptote.

2.3.10 Oscillation and Nonexistent Limits

The function sin(1/x) oscillates increasingly rapidly as x approaches zero.

def oscillating(x):
    return np.sin(1/x)

n = np.arange(1, 8)
x_to_one = 1 / (np.pi/2 + 2*np.pi*n)
x_to_minus_one = 1 / (3*np.pi/2 + 2*np.pi*n)

print(oscillating(x_to_one))       # values near 1
print(oscillating(x_to_minus_one)) # values near -1

Both input sequences approach zero, but one set of outputs stays near 1 and the other stays near −1. The function does not approach a single number, so the limit does not exist.

A Small Table Can Miss Oscillation

Carelessly chosen sample points may suggest a false pattern. Combine numerical tables with a graph and mathematical reasoning.

2.3.11 Floating-Point Limitations

Computers store approximations to real numbers. Extremely small distances can cause rounding or cancellation.

For

u(x) = (√(1 + x) − 1)/x,

the limit as x approaches zero is 1/2. Compare the original formula with its rationalized form:

def u_original(x):
    return (np.sqrt(1 + x) - 1) / x

def u_stable(x):
    return 1 / (np.sqrt(1 + x) + 1)

for x in [1e-4, 1e-8, 1e-12, 1e-16]:
    print(x, u_original(x), u_stable(x))

For very small x, subtracting two nearly equal numbers can erase significant digits. The stable formula continues to approach 0.5.

Closer Is Not Always Better

Use several sensible distances and look for a stable trend. Do not assume the smallest representable distance gives the best estimate.

2.3.12 A Reusable Limit-Table Helper

def limit_table(function, a, distances=None):
    if distances is None:
        distances = np.geomspace(1e-1, 1e-6, 6)

    left_x = a - distances
    right_x = a + distances

    print("     left x        f(left)       right x       f(right)")
    for xl, xr in zip(left_x, right_x):
        print(f"{xl:12.8f}  {function(xl):12.8f}  "
              f"{xr:12.8f}  {function(xr):12.8f}")

limit_table(f, 2)

This helper organizes evidence. It does not automatically determine or prove the limit.

2.3.13 Tutorial Activity: Limit Detective

For each function, create a left-right table, draw an appropriate graph, and state what the evidence suggests.

  1. f(x) = (x2 − 9)/(x − 3) as x → 3.
  2. g(x) = |x|/x as x → 0.
  3. h(x) = 1/(x + 1)2 as x → −1.
  4. p(x) = (5x2 − 2)/(x2 + 7) as x → ∞.

For every conclusion, identify whether it is a finite limit, an infinite limit, or a limit that does not exist.

Show one possible solution 
import numpy as np
import matplotlib.pyplot as plt

distances = np.geomspace(1e-1, 1e-6, 6)

def f(x):
    return (x**2 - 9) / (x - 3)

def g(x):
    return np.abs(x) / x

def h(x):
    return 1 / (x + 1)**2

def p(x):
    return (5*x**2 - 2) / (x**2 + 7)

# 1: both sides approach 6
print(f(3 - distances))
print(f(3 + distances))

# 2: left approaches -1, right approaches 1; DNE
print(g(-distances))
print(g(distances))

# 3: both sides grow toward positive infinity
print(h(-1 - distances))
print(h(-1 + distances))

# 4: outputs approach 5
large_x = np.array([10, 100, 1000, 10000], dtype=float)
print(p(large_x))

2.3.14 Common Errors

ProblemWhy it happens and what to do
Evaluating only at x = aA limit concerns nearby inputs. Use values on both sides.
Including the undefined target in an arrayExclude it and approach with nonzero distances.
Checking only one sideA two-sided limit needs matching left- and right-hand behaviour.
Reporting a large number as “the limit”Determine whether outputs are unbounded rather than approaching a finite value.
Treating inf as a real-number answerIt represents overflow or unbounded behaviour, not an ordinary function value.
Trusting one or two rowsUse several shrinking distances and inspect the trend.
Using distances that are too smallFloating-point rounding can overwhelm the calculation.
Claiming the table proves the limitFinite numerical evidence can support a conjecture but cannot check every nearby input.

Section Summary

  • A limit describes nearby behaviour and may differ from the function value.
  • Shrinking distances generate systematic left- and right-hand input sequences.
  • A two-sided finite limit requires equal one-sided limits.
  • Unbounded output suggests an infinite limit and often a vertical asymptote.
  • Large positive and negative inputs reveal limits at infinity and horizontal asymptotes.
  • Oscillation can prevent a function from approaching one value.
  • Numerical tables and graphs provide evidence, but floating-point effects and limited sampling require caution.
