0.5.1 Your First Code Cell

A program is a sequence of instructions that a computer executes. In Google Colab, the instructions are usually divided into code cells. A cell can contain one instruction or several related instructions.

Create and Run the Program

  1. Open Google Colab.
  2. Create a new notebook.
  3. Rename it MATH1516_First_Program.ipynb.
  4. Enter the code below in the first code cell.
  5. Run the cell using the play button or Shift+Enter.
print("Hello, MATH 1516!")
print("I am running my first Python program.")

The output is:

Hello, MATH 1516!
I am running my first Python program.

The print() function displays a value as output. Text must be placed inside quotation marks. Python accepts either double quotation marks or single quotation marks, provided that the pair matches.

Notebook Output and print()

Colab automatically displays the value of the final expression in a cell. However, print() is clearer when a program has several results or when each result needs a label.

Comments

A comment begins with #. Python ignores everything after the number sign on that line. Comments explain the purpose of code to a reader. 

# This program displays a course message.
print("Welcome to the tutorial!")  # Display the message.

Useful comments explain the purpose or reasoning behind a step. They should not merely repeat an obvious instruction.

0.5.2 Variables and Assignment

A variable is a name that refers to a value. The assignment operator = stores the value on its right under the name on its left. 

course = "MATH 1516"
number_of_students = 28
tutorial_length = 80

print(course)
print(number_of_students)
print(tutorial_length)

Read number_of_students = 28 as “assign the value 28 to the variable number_of_students.” In Python, assignment is not an equation asserting that two expressions are permanently equal.

Updating a Variable

score = 7
print("Original score:", score)

score = score + 2
print("Updated score:", score)

Python first evaluates the right side using the current value of score. It then stores the result, 9, under the same name.

Variable Naming Rules

  • A name may contain letters, digits, and underscores.
  • A name cannot begin with a digit.
  • A name cannot contain a space or hyphen.
  • Names are case-sensitive: score and Score are different.
  • A Python keyword such as for, if, or class cannot be used as a variable name.
  • Use descriptive names written in snake_case, such as final_score.
Name Valid? Reason
matrix_size Yes Uses letters and an underscore.
score2 Yes A digit may appear after the first character.
2score No A variable name cannot begin with a digit.
final score No Spaces are not allowed in variable names.
sum Technically, but avoid it It hides Python's built-in sum() function.

0.5.3 Basic Data Types

Every value has a data type. The type determines how Python represents the value and which operations are meaningful.

Type Meaning Examples
int Integer 7, 0, -12
float Number with a decimal point 3.14, -0.5, 2.0
str Text, called a string "Python", "1516"
bool A logical value True, False

Use type() to inspect the type of a value:

students = 28
average = 8.5
course = "MATH 1516"
is_tutorial_day = True

print(type(students))
print(type(average))
print(type(course))
print(type(is_tutorial_day))

A Number and a String Are Different

The integer 1516 can be used in arithmetic. The string "1516" is text. Quotation marks change the value's type and therefore change which operations Python can perform.

0.5.4 Arithmetic in Python

Python can be used as a calculator.

Operation Python Operator Example Result
Addition + 7 + 3 10
Subtraction - 7 - 3 4
Multiplication * 7 * 3 21
Division / 7 / 2 3.5
Floor division // 7 // 2 3
Remainder % 7 % 2 1
Exponentiation ** 7 ** 2 49

Python Does Not Use ^ for Powers

Write x ** 2 for x squared. The symbol ^ performs a different operation in Python and should not be used for exponents.

Order of Operations

Python follows the usual order of operations: parentheses, exponents, multiplication and division, then addition and subtraction. Operations at the same level are normally evaluated from left to right. 

result_1 = 2 + 3 * 4
result_2 = (2 + 3) * 4

print(result_1)
print(result_2)

The outputs are 14 and 20.

A Mathematical Calculation

radius = 5
pi = 3.14159

area = pi * radius ** 2
circumference = 2 * pi * radius

print("Area:", area)
print("Circumference:", circumference)

Longer expressions should be written so their mathematical structure is visible. Use parentheses whenever they make the intended order clearer.

0.5.5 Strings and Readable Output

A string is a sequence of characters used to represent text. Strings can be stored in variables, printed, and combined. 

first_name = "Ada"
last_name = "Lovelace"
full_name = first_name + " " + last_name

print(full_name)

The + operator joins strings. This is called concatenation.

Formatted Strings

An f-string places variable values inside text. Put the letter f before the opening quotation mark and place expressions inside braces. 

course = "MATH 1516"
score = 18
total = 20

print(f"Course: {course}")
print(f"Score: {score} out of {total}")
print(f"Percentage: {100 * score / total}%")

To show a fixed number of decimal places, add a formatting instruction:

value = 10 / 3
print(f"The value is approximately {value:.2f}.")

The output is The value is approximately 3.33.

Compute First, Then Explain

Store an important result in a descriptively named variable. Then use an f-string to label the value and include units. This makes mathematical output easier to interpret.

0.5.6 Accepting User Input

The input() function pauses a program and asks the user to enter a value. In Colab, an input box appears beneath the code cell. 

name = input("Enter your name: ")
print(f"Hello, {name}!")

The value returned by input() is always a string. Convert the string before performing numerical calculations.

Function Conversion Example
int() Converts to an integer int("12") gives 12
float() Converts to a decimal number float("12.5") gives 12.5
str() Converts to text str(12) gives "12"

Example: Rectangle Calculator

This program asks for the dimensions of a rectangle, calculates its area and perimeter, and displays labelled results. 

# Ask the user for the rectangle's dimensions.
length = float(input("Enter the length: "))
width = float(input("Enter the width: "))

# Calculate the requested quantities.
area = length * width
perimeter = 2 * (length + width)

# Display the results.
print(f"Area: {area:.2f} square units")
print(f"Perimeter: {perimeter:.2f} units")

Input Must Match the Conversion

Entering text such as five when the program calls float() produces a ValueError. For now, rerun the cell and enter a valid number. A later section will discuss errors in more detail.

0.5.7 A Complete Mathematical Program

A clear program often follows an input–process–output structure:

  1. Input: obtain or define the required data.
  2. Process: perform the calculations.
  3. Output: display the result with a meaningful label.

Example: Distance Between Two Points

For points (x1, y1) and (x2, y2), the distance is the square root of the sum of the squared coordinate differences. 

# Input
x1 = float(input("Enter x1: "))
y1 = float(input("Enter y1: "))
x2 = float(input("Enter x2: "))
y2 = float(input("Enter y2: "))

# Process
change_x = x2 - x1
change_y = y2 - y1
distance = (change_x ** 2 + change_y ** 2) ** 0.5

# Output
print(f"The distance is {distance:.3f} units.")

If the points are (1, 2) and (4, 6), the program displays a distance of 5.000 units.

Trace the Program

Variable Value Meaning
change_x 4 - 1 = 3 Horizontal change
change_y 6 - 2 = 4 Vertical change
distance (3**2 + 4**2)**0.5 = 5.0 Distance between the points

0.5.9 Reading Code by Hand

Before running a cell, predict its output. This develops the ability to trace a program and identify mistakes. 

a = 4
b = 3
c = a ** 2 + b ** 2
a = a + 1

print(a)
print(b)
print(c)
Show the output and explanation 
5
3
25

The value of c is calculated while a is 4. Updating a afterward does not automatically recalculate c.

0.5.12 Good Habits from the Beginning

  • Use descriptive variable names.
  • Include spaces around arithmetic and assignment operators.
  • Separate input, calculations, and output into logical groups.
  • Add short comments when the purpose of a step is not obvious.
  • Label numerical output and include units when appropriate.
  • Predict the result before running a cell.
  • Test a program using simple values whose correct result is known.
  • Run notebook cells from top to bottom before sharing your work.

Section Summary

  • A Python program is a sequence of executable instructions.
  • print() displays output, and # begins a comment.
  • The assignment operator stores a value under a variable name.
  • Common types include int, float, str, and bool.
  • Python uses ** for powers and follows the usual order of operations.
  • F-strings combine text, values, and formatting in readable output.
  • input() returns text, so numerical input must usually be converted.
  • A clear mathematical program follows an input–process–output structure.
