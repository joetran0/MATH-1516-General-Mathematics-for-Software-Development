About These Activities

This website contains short Python activities for MATH 1516 tutorials. The material is organized into parts and numbered sections, similar to a textbook. Each section will eventually have its own lesson, examples, code, exercises, and solutions.

No previous Python experience is required.

Part 0: Getting Started with Python

This part introduces the software and basic Python skills needed for the course.

  1. 0.1 Introduction to Python What Python is, why it is useful in mathematics, and how it will be used in MATH 1516.
  2. 0.2 Installing Python Install a current version of Python on Windows or macOS and confirm that it works.
  3. 0.3 Choosing a Coding Environment An introduction to IDLE, Visual Studio Code, Jupyter Notebook, and Google Colab.
  4. 0.4 Installing Python Packages Use pip to install NumPy, Matplotlib, SymPy, pandas, and SciPy.
  5. 0.5 Your First Python Program Run a short program, print results, use variables, and perform basic calculations.
  6. 0.6 Lists, Loops, and Functions The basic Python structures that will appear throughout the activities.
  7. 0.7 Common Errors and Troubleshooting Read error messages and fix common problems involving syntax, indentation, and missing packages.

Part 1: Linear Systems and Matrices

Use NumPy to represent matrices and investigate systems of linear equations.

  1. 1.1 Creating Vectors and Matrices Create NumPy arrays and access individual entries, rows, and columns.
  2. 1.2 Matrix Terminology and Dimensions Identify matrix size, entries, rows, columns, diagonal entries, and special matrices.
  3. 1.3 Matrix Arithmetic Perform addition, scalar multiplication, matrix multiplication, and transposition.
  4. 1.4 Linear Systems in Matrix Form Convert a system of equations into the form Ax = b.
  5. 1.5 Solving Linear Systems Use numpy.linalg.solve and compare the output with algebraic methods.
  6. 1.6 Visualizing Matrices Display matrix entries using imshow and interpret colour-based matrix plots.
  7. 1.7 Applications of Linear Systems Model small problems involving mixtures, costs, networks, or resource allocation.

Part 2: Differential Calculus

Use Python to explore functions, limits, derivatives, and optimization.

  1. 2.1 Defining and Evaluating Functions Write Python functions and evaluate them at selected input values.
  2. 2.2 Plotting Functions Use Matplotlib to graph functions and adjust the viewing window.
  3. 2.3 Exploring Limits Numerically Use tables and graphs to investigate function behaviour near a point.
  4. 2.4 Approximating Derivatives Estimate derivatives with difference quotients and examine approximation error.
  5. 2.5 Symbolic Differentiation Use SymPy to calculate and simplify derivatives.
  6. 2.6 Tangent Lines and Rates of Change Plot tangent lines and interpret derivatives in applied settings.
  7. 2.7 Optimization Use derivatives and graphs to locate and interpret maximum and minimum values.

Part 3: Statistics

Use pandas, NumPy, and Matplotlib to summarize and visualize data.

  1. 3.1 Working with Data Create a dataset and import data from a CSV file.
  2. 3.2 Measures of Centre Calculate and compare the mean, median, and mode.
  3. 3.3 Measures of Spread Calculate the range, variance, standard deviation, and interquartile range.
  4. 3.4 Histograms and Box Plots Create statistical graphs and use them to describe a distribution.
  5. 3.5 Scatter Plots and Correlation Investigate relationships between two numerical variables.
  6. 3.6 Comparing Data Groups Use numerical summaries and graphs to compare two or more datasets.

Part 4: Probability

Use random simulation to investigate probability models and distributions.

  1. 4.1 Random Experiments Simulate coins, dice, cards, and other simple random experiments.
  2. 4.2 Experimental Probability Compare simulated relative frequencies with theoretical probabilities.
  3. 4.3 Discrete Random Variables Represent values and probabilities and calculate expected value.
  4. 4.4 Binomial Distribution Calculate and simulate binomial probabilities.
  5. 4.5 Normal Distribution Plot normal curves and calculate probabilities using SciPy.
  6. 4.6 Monte Carlo Methods Estimate a quantity by repeating a random experiment many times.
