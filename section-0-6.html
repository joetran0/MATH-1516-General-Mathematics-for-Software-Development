0.6.1 What Is a List?

A list stores an ordered collection of values under one variable name. Lists are useful when a program must work with several related values, such as tutorial scores, matrix entries, or repeated measurements. 

scores = [8, 10, 7, 9, 6]
print(scores)

Square brackets mark the beginning and end of the list. Commas separate its elements. The order of the elements is preserved.

Common List Operations

scores = [8, 10, 7, 9, 6]

print("Number of scores:", len(scores))
print("Total:", sum(scores))
print("Smallest:", min(scores))
print("Largest:", max(scores))
print("Mean:", sum(scores) / len(scores))
Expression Purpose Result for scores
len(scores) Number of elements 5
sum(scores) Sum of numerical elements 40
min(scores) Smallest element 6
max(scores) Largest element 10

A list can also contain strings or a mixture of data types:

topics = ["matrices", "calculus", "statistics", "probability"]
student_record = ["Ada", 18, 20, True]

Prefer Consistent Data

Python allows mixed lists, but mathematical lists are usually easier to process when all elements represent the same kind of quantity.

0.6.2 Indexing and Slicing

Each list element has a position called an index. Python begins counting at zero.

Element 8 10 7 9 6
Index 0 1 2 3 4
Negative index -5 -4 -3 -2 -1 
scores = [8, 10, 7, 9, 6]

print(scores[0])   # First element
print(scores[2])   # Third element
print(scores[-1])  # Last element

The First Index Is Zero

For a list with five elements, the valid non-negative indices are 0 through 4. Trying to access scores[5] produces an IndexError.

Slicing a List

A slice selects several consecutive elements. The starting index is included, but the stopping index is excluded. 

scores = [8, 10, 7, 9, 6]

print(scores[1:4])  # [10, 7, 9]
print(scores[:3])   # [8, 10, 7]
print(scores[2:])   # [7, 9, 6]

Changing a List

Lists are mutable, meaning that their contents can be changed.

scores = [8, 10, 7]

scores[2] = 9
scores.append(6)

print(scores)

The output is [8, 10, 9, 6].

Method Purpose Example
append(value) Add one element to the end scores.append(6)
insert(index, value) Add an element at a selected index scores.insert(1, 5)
remove(value) Remove the first matching value scores.remove(5)
pop() Remove and return the final element last_score = scores.pop()

0.6.3 Repetition with for Loops

A loop repeats a block of code. A for loop is particularly useful when the program should process each element of a list. 

scores = [8, 10, 7, 9, 6]

for score in scores:
    print(score)

During each iteration, the variable score refers to the next list element. The indented line is executed once for each value.

Indentation Is Part of Python Syntax

The colon begins the loop body, and the indented lines belong to the loop. Colab normally inserts four spaces automatically. Code that should run after the loop must return to the original indentation level.

Transforming Each Value

numbers = [1, 2, 3, 4, 5]

for number in numbers:
    square = number ** 2
    print(f"{number} squared is {square}")

The loop repeats the same calculation for every value without requiring five separate copies of the instruction.

Building a New List

numbers = [1, 2, 3, 4, 5]
squares = []

for number in numbers:
    squares.append(number ** 2)

print(squares)

The output is [1, 4, 9, 16, 25].

An Accumulator

An accumulator is a variable that is updated during each loop iteration. The following loop recreates the behaviour of sum(). 

scores = [8, 10, 7, 9, 6]
total = 0

for score in scores:
    total = total + score

mean = total / len(scores)

print("Total:", total)
print("Mean:", mean)

Use Built-ins When Available

Writing an accumulator helps explain how repetition works. In ordinary programs, sum(scores) is shorter and clearer when only the total is needed.

0.6.4 Generating Integers with range()

The range() function generates a sequence of integers. It is commonly used when a loop must repeat a known number of times.

Expression Generated Values
range(5) 0, 1, 2, 3, 4
range(2, 6) 2, 3, 4, 5
range(2, 11, 2) 2, 4, 6, 8, 10

As with list slicing, the stopping value is excluded. Therefore, range(1, 6) generates the integers 1 through 5. 

for n in range(1, 6):
    print(n, n ** 2)

Calculate a Finite Sum

The following program calculates 1 + 2 + ... + 100:

total = 0

for n in range(1, 101):
    total = total + n

print(total)

The output is 5050.

Repeat an Action a Fixed Number of Times

for repetition in range(3):
    print("Run the experiment")

The variable name describes the current iteration. If that value is not needed, an underscore is a common placeholder: 

for _ in range(3):
    print("Run the experiment")

0.6.5 A Brief Introduction to while Loops

A while loop repeats while a condition remains true. Use it when the number of iterations is not known in advance. 

value = 1

while value < 20:
    print(value)
    value = value * 2

The loop prints 1, 2, 4, 8, and 16.

A while Loop Must Make Progress

If the condition never becomes false, the loop continues indefinitely. Confirm that some value inside the loop changes. If a Colab cell will not stop, use the stop button beside the cell.

0.6.6 Defining Functions

A function is a named, reusable block of code. Functions help divide a longer program into smaller tasks and prevent repeated code. 

def greet():
    print("Welcome to MATH 1516!")

greet()

The keyword def begins the function definition. The function body is indented. Defining a function does not run its body; the separate call greet() runs it.

Parameters and Arguments

def square(number):
    result = number ** 2
    return result

print(square(5))
print(square(1.5))

The name number is a parameter. The values 5 and 1.5 are arguments supplied when the function is called.

return Versus print()

Instruction Purpose
print(value) Displays a value for the user.
return value Sends a value back to the code that called the function. 
def rectangle_area(length, width):
    return length * width

area_1 = rectangle_area(5, 3)
area_2 = rectangle_area(2.5, 4)
combined_area = area_1 + area_2

print(f"Combined area: {combined_area}")

Returning the two areas makes them available for another calculation. A function that only prints its result is less reusable.

Documenting a Function

A short string directly beneath the function header is called a docstring. It describes what the function calculates. 

def average(values):
    """Return the arithmetic mean of a non-empty list."""
    return sum(values) / len(values)

scores = [8, 10, 7, 9, 6]
print(average(scores))

Function Names Should Describe Actions

Names such as calculate_mean, distance, and convert_temperature communicate the purpose of a function better than names such as do_it or function1.

0.6.7 Combining Lists, Loops, and Functions

Example: Apply a Function to Every Value

def fahrenheit(celsius):
    """Convert a Celsius temperature to Fahrenheit."""
    return 9 * celsius / 5 + 32

celsius_values = [0, 10, 20, 30, 40]
fahrenheit_values = []

for temperature in celsius_values:
    converted = fahrenheit(temperature)
    fahrenheit_values.append(converted)

print(celsius_values)
print(fahrenheit_values)

The list supplies the data, the loop visits each value, and the function performs the reusable calculation. This pattern appears throughout numerical mathematics and data analysis.

Generating a Table of Function Values

def f(x):
    return x ** 2 - 3 * x + 2

for x in range(-2, 6):
    print(f"x = {x:2d}, f(x) = {f(x):2d}")

A table of values can help investigate a function before graphing it. Later sections will use NumPy and Matplotlib to perform similar tasks more efficiently and visualize the results.

A List of Lists

A list can contain other lists. This provides a basic way to represent a matrix:

matrix = [
    [1, 2, 3],
    [4, 5, 6]
]

print(matrix[0])     # First row
print(matrix[1][2])  # Entry in second row, third column

Part 1 will use NumPy arrays for most matrix calculations, but nested lists help show how rows and entries can be organized.

0.6.8 Tutorial Activity: Summarize a Set of Scores

Build the Program in Colab

  1. Create the list scores = [72, 85, 91, 68, 88, 76].
  2. Write a function named calculate_mean that returns the arithmetic mean of a list.
  3. Use a for loop to print each score and its square.
  4. Create an empty list named percent_as_decimal.
  5. Use another loop to divide each score by 100 and append the result to the new list.
  6. Display the number of scores, minimum, maximum, mean, and decimal list.
  7. Change one score, predict which results will change, and run the cell again.
Show a sample solution 
def calculate_mean(values):
    """Return the arithmetic mean of a non-empty list."""
    return sum(values) / len(values)

scores = [72, 85, 91, 68, 88, 76]

for score in scores:
    print(f"Score: {score}, square: {score ** 2}")

percent_as_decimal = []

for score in scores:
    percent_as_decimal.append(score / 100)

print("Count:", len(scores))
print("Minimum:", min(scores))
print("Maximum:", max(scores))
print(f"Mean: {calculate_mean(scores):.2f}")
print("Decimals:", percent_as_decimal)

Extension: Running Totals

Use an accumulator to create a new list containing the running total after each score. For the list [3, 5, 2], the running totals would be [3, 8, 10].

Show an extension solution 
values = [3, 5, 2]
running_totals = []
total = 0

for value in values:
    total = total + value
    running_totals.append(total)

print(running_totals)

0.6.9 Reading Code by Hand

Predict the output before running the cell:

def change(values):
    results = []

    for value in values:
        results.append(2 * value + 1)

    return results

numbers = [0, 2, 4]
print(change(numbers))
Show the answer

The output is [1, 5, 9]. The loop applies the rule 2 * value + 1 to each list element and appends each result to a new list.

0.6.10 Common Mistakes

Mistake Example Correction
Starting at index 1 values[1] for the first element Use values[0].
Including the stopping value of range() Expecting range(5) to include 5 Remember that it generates 0 through 4.
Missing a colon for value in values Add : at the end of the header.
Incorrect indentation Loop or function body aligned with its header Indent the complete body consistently.
Forgetting to initialize an accumulator Using total before assigning a value Set total = 0 before the loop.
Printing instead of returning A calculation function only calls print() Use return when later code needs the result.

0.6.11 Concept Check

  1. What index identifies the first element of a list?
  2. What does values[-1] select?
  3. Why does range(1, 5) not include 5?
  4. What determines which instructions belong to a loop or function?
  5. What is an accumulator?
  6. What is the difference between a parameter and an argument?
  7. Why is return useful in a calculation function?
Show suggested answers
  1. Index 0.
  2. The final element.
  3. The stopping value of range() is excluded.
  4. Indentation determines the code block.
  5. A variable that is repeatedly updated, often to store a running total.
  6. A parameter is a name in the function definition; an argument is a value supplied in a function call.
  7. It sends the result back so other code can store it or use it in another calculation.

Section Summary

  • A list stores an ordered collection of values.
  • Python list indices begin at zero, and slices exclude the stopping index.
  • Lists are mutable and can be extended using append().
  • A for loop processes each value in a collection.
  • range() generates integers and excludes its stopping value.
  • An accumulator stores a result that changes during a loop.
  • A function is a named, reusable block of code defined with def.
  • Parameters receive arguments, and return sends a result back to the caller.
  • Lists, loops, and functions form a common pattern for repeated mathematical calculations.
